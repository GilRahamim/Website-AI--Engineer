# 03 — מפרט Frontend

## Design System

### צבעים (OKLCH tokens) — לשמר מהבסיס הקיים
הגדר ב־`src/styles/tokens.css` כמשתני CSS, עם override לערכה כהה. הערכים הבאים הם הבסיס הקיים (שמור עליהם):

```css
:root {
  --kb-bg: oklch(97.5% 0.005 260);      --kb-surface: oklch(99.2% 0.003 260);
  --kb-surface2: oklch(95.5% 0.007 260); --kb-border: oklch(90% 0.01 260);
  --kb-border-strong: oklch(83% 0.014 260);
  --kb-text: oklch(23% 0.02 260); --kb-text2: oklch(38% 0.018 260); --kb-muted: oklch(52% 0.016 260);
  --kb-accent: oklch(54% 0.16 260); --kb-accent-soft: oklch(94% 0.03 260);
  /* קטגוריות: hue לכל קטגוריה — algorithms/concepts/metrics/formulas/architectures */
}
:root[data-theme="dark"] {
  --kb-bg: oklch(19% 0.012 260); --kb-surface: oklch(23% 0.014 260);
  --kb-surface2: oklch(27% 0.016 260); --kb-border: oklch(32% 0.016 260);
  --kb-border-strong: oklch(40% 0.018 260);
  --kb-text: oklch(93% 0.006 260); --kb-text2: oklch(80% 0.01 260); --kb-muted: oklch(64% 0.014 260);
  --kb-accent: oklch(74% 0.14 260); --kb-accent-soft: oklch(32% 0.06 260);
}
```

### הוסף tokens שחסרו בבסיס (עומק ותנועה) — P0
זה מה שהופך את התחושה מ"dashboard" ל"מוצר":

```css
:root {
  --kb-shadow-sm: 0 1px 2px oklch(20% 0.02 260 / 0.06), 0 1px 3px oklch(20% 0.02 260 / 0.08);
  --kb-shadow-md: 0 4px 12px oklch(20% 0.02 260 / 0.10);
  --kb-shadow-lg: 0 12px 32px oklch(20% 0.02 260 / 0.14);
  --kb-focus-ring: 0 0 0 2px var(--kb-bg), 0 0 0 4px var(--kb-accent);
  --kb-ease: cubic-bezier(.2,.6,.2,1);
}
:root[data-theme="dark"] {
  --kb-shadow-sm: 0 1px 2px oklch(0% 0 0 / 0.4);
  --kb-shadow-md: 0 4px 14px oklch(0% 0 0 / 0.45);
  --kb-shadow-lg: 0 14px 36px oklch(0% 0 0 / 0.55);
}
```

### טיפוגרפיה
Heebo (גוף) + JetBrains Mono (קוד), **woff2 בלבד** (מסמך 05). type scale עקבי: 12 / 13 / 14 / 16 / 20 / 28px. כותרות 700–800, גוף 400–500, טקסט משני `--kb-muted`. **ללא `letter-spacing` שלילי בעברית**. ריווח שורות גוף 1.6.

### חוקי אינטראקציה גלובליים
- כל אלמנט אינטראקטיבי מקבל `:focus-visible { box-shadow: var(--kb-focus-ring); outline: none; }` — **חובה (P0, היה חסר)**.
- מעברים: `transition: … 160ms var(--kb-ease)` על hover/focus.
- `@media (prefers-reduced-motion: reduce)` — לבטל transforms ואנימציות.

## פיצ'רים קיימים לשחזר (יש בבסיס הנוכחי — לשמר במלואם)
1. **Header** דביק: לוגו, מותג (שתי שורות), כפתור ערכת נושא, כפתור התקנת PWA (חדש).
2. **Hero** עם כותרת, תיאור, וסטטיסטיקות כ"כרטיסי מדד".
3. **Sidebar** ניווט לפי מודולים וקטגוריות, מוני פריטים, מצב מקופל, תפריט מובייל.
4. **חיפוש** חופשי (עכשיו עם נרמול עברית + הדגשת מונח).
5. **סינון מרובה** (multi-select): מודולים + קטגוריות; OR בתוך סוג, AND בין סוגים. שבבי סינון פעילים עם הסרה + "נקה הכול".
6. **Accordion**: קיפול קבוצות + "הרחב/כווץ הכול", מצב נשמר.
7. **מיון**: מקורי / א־ת / קטגוריה (`localeCompare('he')`).
8. **תצוגת רשת / רשימה דחוסה**, נשמר.
9. **קורא נושא** (עמוד/מודל): breadcrumb, badge, תוכן מלא, נוסחאות, נושאים קשורים.
10. **נוסחאות KaTeX** — טעינה עצלה, `displayMode` רק לנוסחאות בלוק (inline נשאר inline).
11. **ערכות נושא** בהיר/כהה + סנכרון מערכת + שמירה.

## תיקוני P0 (מהסקירה — חובה)
- **הצללות ו־hover-lift על כרטיסים:** `box-shadow: var(--kb-shadow-sm)` במנוחה; ב־hover `translateY(-2px)` + `--kb-shadow-md`.
- **`focus-visible` בכל אלמנט** (ראה מעלה).
- **ניווט מקלדת מלא ברשת:** חצים לניווט בין כרטיסים, `Enter` לפתיחה, `Home/End`. בנוסף לקיצורים הקיימים (`/`, `Esc`, `?`).
- **הבחנת משטחים:** רקע → surface → כרטיס מוגבה, ברורה בשתי הערכות.

## פיצ'רים חדשים — כלי למידה (הלב)
כל אלה נשמרים ב־IndexedDB (מסמך 02) ומסונכרנים (מסמך 04). כולם עובדים גם בלי חשבון.

### A. מעקב התקדמות
- על כל כרטיס/קורא: מתג מצב `לא נלמד / בלמידה / שולט`.
- פס התקדמות פר־מודול ב־sidebar וב־hero ("שלטת ב־X מתוך Y").
- מסנן "הצג רק: לא נלמד / בלמידה" משתלב בסינון הקיים.

### B. מועדפים + נצפו לאחרונה
- כוכב לסימון מועדף (על כרטיס וקורא).
- מדף "אחרונים" (12 אחרונים) ומדף "מועדפים" ב־sidebar/בית.

### C. הערות אישיות
- בקורא: אזור "ההערות שלי" (textarea, שמירה אוטומטית עם debounce).
- הערות נכללות בחיפוש (אופציונלי: טוגל "כלול הערות").

### D. כרטיסיות + חזרה מרווחת (Spaced Repetition)
- עמוד `Flashcards`: מציג כותרת → המשתמש נזכר → חושף הגדרה → מדרג `שוב / קשה / טוב / קל`.
- אלגוריתם SM-2 מפושט ב־`lib/srs.ts` (ease, interval, due). ראה מסמך 02 לסכימת `SrsCard`.
- אפשר לסנן חפיסה לפי מודול/קטגוריה/מצב.

### E. מצב מבחן (Quiz)
- עמוד `Quiz`: שאלות רב־ברירה שנבנות אוטומטית — "לאיזה מושג שייכת ההגדרה?" (מסיחים מאותה קטגוריה), או "הסבר את X" עם חשיפה עצמית.
- סיכום ציון בסוף + סימון פריטים שנפלו לחזרה ב־SRS.

### F. חזרה יומית (Daily Review)
- בעמוד הבית: כרטיס "היום ללמידה" — N פריטים ש־`dueAt <= now` מה־SRS, + "מושג אקראי".
- אופציונלי: badge עם מספר הפריטים שממתינים לחזרה.

### G. מפת ידע (Knowledge Graph)
- עמוד `Map`: גרף אינטראקטיבי (מושגים כצמתים, `related_match` כקשתות). לחיצה על צומת פותחת את הקורא.
- ספרייה: `react-force-graph` או `d3-force`. סינון לפי קטגוריה/מודול. שימושי לניווט אסוציאטיבי.

### H. Command Palette (Cmd/Ctrl+K)
- חלונית קפיצה מהירה: חיפוש נושא לפי שם ומעבר אליו, + פעולות ("החלף ערכת נושא", "פתח כרטיסיות"). מאיץ מאוד שימוש יומיומי.

## עמודים (routes)
`/` בית (רשת+חיפוש+סינון+דשבורד למידה) · `/topic/:id` קורא · `/flashcards` · `/quiz` · `/map` · `/settings` (חשבון/סנכרון/ערכת נושא/ייצוא).

## נגישות (חובה, לא אופציונלי)
`focus-visible` בכל אינטראקטיבי · ניווט מקלדת מלא · `aria-label`/`role` · ניגוד AA בשתי הערכות · `prefers-reduced-motion` · יעדי מגע ≥44px במובייל.
