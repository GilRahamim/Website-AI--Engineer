# Phase 4, Sub-project #1 — PWA Installability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the app installable — real manifest, generated icons, a service worker registered via `vite-plugin-pwa`, and an in-app install button — without yet caching anything beyond the built app shell.

**Architecture:** A one-time Node script rasterizes the 🧠 emoji (via `twemoji`'s SVG source + `sharp`) into the icon files a Web App Manifest needs; a static `manifest.webmanifest` and new `index.html` tags declare installability; `vite-plugin-pwa` generates the service worker at build time (default app-shell precache only) and is registered in `main.tsx`; a small `useInstallPrompt` hook captures the browser's `beforeinstallprompt` event and a new `Header` button surfaces it.

**Tech Stack:** React 19, TypeScript, Vite, `vite-plugin-pwa` (Workbox codegen), `sharp` + `twemoji` (build-time only, devDependencies), Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-07-phase4-pwa-installability-design.md`

## Global Constraints

- `twemoji` and `sharp` are devDependencies only — icon generation is a one-time script, its PNG output is committed like any other static asset, and neither package ships in the app bundle.
- Icon source: Twemoji's SVG for U+1F9E0 (🧠), not a hand-drawn redesign and not the codebase's `1f9e0` emoji rendered via a system font.
- `#0f1220` is the one static color used everywhere a manifest/meta tag needs a color (`background_color`, `theme_color`, maskable-icon background) — it already matches the existing hardcoded `<meta name="theme-color">` and the dark-theme `--kb-bg` token. This is the one documented, deliberate exception to golden rule 7 (tokens only) — a manifest file and `<meta>` tags cannot reference CSS custom properties.
- This sub-project precaches the app shell only (JS/CSS/HTML — `vite-plugin-pwa`'s default `workbox.globPatterns`). It must NOT add runtime caching for `topic-content/`/`topic-assets/`, and must NOT precache `topics.clean.json`/`modules.json`/`search-index.json` — that is sub-project #2's job, not this one.
- No install-button fallback UI for browsers that never fire `beforeinstallprompt` (Firefox, Safari) — the button simply never renders there.
- RTL, both themes, `--kb-*` tokens (except the documented manifest/meta-tag exception above), `min-h-11` touch targets, keyboard accessibility — apply to the new install button like every other interactive element in this codebase.

Create `kb-app/scripts/generate-icons.mjs`:

```js
import { createRequire } from 'node:module';
import { mkdirSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import sharp from 'sharp';

const require = createRequire(import.meta.url);
const __dirname = dirname(fileURLToPath(import.meta.url));

// Twemoji ships one SVG per emoji at assets/svg/<hex-codepoint>.svg.
// U+1F9E0 is the brain emoji (🧠) — the same one already used as this
// app's brand mark in Header.tsx.
const twemojiSvgPath = join(dirname(require.resolve('twemoji/package.json')), 'assets', 'svg', '1f9e0.svg');

const publicDir = join(__dirname, '..', 'public');
const iconsDir = join(publicDir, 'icons');
mkdirSync(iconsDir, { recursive: true });

const BACKGROUND = '#0f1220';

async function generate() {
  await sharp(twemojiSvgPath).resize(192, 192).png().toFile(join(iconsDir, 'icon-192.png'));
  await sharp(twemojiSvgPath).resize(512, 512).png().toFile(join(iconsDir, 'icon-512.png'));

  // Maskable icon: the glyph at ~80% scale, centered over a solid
  // background square — the standard "safe zone" so Android's shape mask
  // doesn't crop the brain at the edges.
  const maskableSize = 512;
  const glyphSize = Math.round(maskableSize * 0.8);
  const glyphBuffer = await sharp(twemojiSvgPath).resize(glyphSize, glyphSize).png().toBuffer();
  await sharp({
    create: { width: maskableSize, height: maskableSize, channels: 4, background: BACKGROUND },
  })
    .composite([{ input: glyphBuffer, gravity: 'center' }])
    .png()
    .toFile(join(iconsDir, 'maskable-512.png'));

  await sharp(twemojiSvgPath).resize(32, 32).png().toFile(join(publicDir, 'favicon.png'));

  console.log('Generated icons in', iconsDir, 'and', join(publicDir, 'favicon.png'));
}

generate().catch((err) => {
  console.error(err);
  process.exitCode = 1;
});
```

- [ ] **Step 3: Implement the hook**

Create `kb-app/src/hooks/useInstallPrompt.ts`:

```ts
import { useEffect, useState } from 'react';

interface BeforeInstallPromptEvent extends Event {
  prompt: () => Promise<void>;
  userChoice: Promise<{ outcome: 'accepted' | 'dismissed' }>;
}

export function useInstallPrompt() {
  const [deferredPrompt, setDeferredPrompt] = useState<BeforeInstallPromptEvent | null>(null);

  useEffect(() => {
    function handleBeforeInstallPrompt(event: Event) {
      event.preventDefault();
      setDeferredPrompt(event as BeforeInstallPromptEvent);
    }
    function handleAppInstalled() {
      setDeferredPrompt(null);
    }
    window.addEventListener('beforeinstallprompt', handleBeforeInstallPrompt);
    window.addEventListener('appinstalled', handleAppInstalled);
    return () => {
      window.removeEventListener('beforeinstallprompt', handleBeforeInstallPrompt);
      window.removeEventListener('appinstalled', handleAppInstalled);
    };
  }, []);

  async function promptInstall() {
    if (!deferredPrompt) return;
    await deferredPrompt.prompt();
    await deferredPrompt.userChoice;
    setDeferredPrompt(null);
  }

  return { canInstall: deferredPrompt !== null, promptInstall };
}
```

(`setDeferredPrompt` is called only inside the two event-handler callbacks, never directly in the `useEffect` body — matching this codebase's established `react-hooks/set-state-in-effect` pattern.)
