📋 הגדרה

פעולת דגימה-יתר (downsampling) המחלקת את מפת התכונות לחלונות קטנים (לדוגמה 2x2) ובוחרת מכל חלון את הערך המקסימלי בלבד — מקטינה את הרזולוציה המרחבית ומדגישה את התכונות הבולטות ביותר.

⚙️ איך זה עובד

  1. בוחרים גודל חלון (לדוגמה 2x2) ו-stride (בדרך כלל שווה לגודל החלון).
  2. מחלקים את מפת התכונות לחלונות לא-חופפים (או חופפים, בהתאם ל-stride).
  3. מכל חלון בוחרים את הערך המקסימלי כפלט.
  4. מחזרים על התהליך לכל הערוצים (channels) במפת התכונות, ומקבלים מפה מוקטנת.

📐 נוסחאות

🎯 שימושים עיקריים

  • Computer Vision — אחרי שכבות קונבולוציה ב-CNN, להקטנת רזולוציה והגדלת receptive field
  • כל ארכיטקטורה שדורשת invariance חלקית להעתקה קטנה (translation) של תכונות

✅ יתרונות

  • מקטין את מספר הפרמטרים והחישוב בשכבות הבאות
  • מספק invariance חלקית להעתקות קטנות של האובייקט בתמונה
  • אין פרמטרים נלמדים — זול חישובית

❌ חסרונות / מגבלות

  • מאבד מידע מרחבי מדויק (downsampling אגרסיבי)
  • לא מתאים תמיד למשימות הדורשות דיוק מיקום גבוה (כגון segmentation מדויק)

💻 קוד לדוגמה (Python / PyTorch)

import torch.nn as nn

pool = nn.MaxPool2d(kernel_size=2, stride=2)
output = pool(feature_map)  # מקטין H,W בחצי, שומר את הערך המקסימלי מכל 2x2

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין Max Pooling ל-Average Pooling?

ת: Max Pooling בוחר את הערך הבולט ביותר בכל חלון (מדגיש תכונות חזקות), בעוד Average Pooling ממצע את כל הערכים בחלון (מחליק את המידע).

ש: איך Max Pooling תורם ל-translation invariance?

ת: אם תכונה זזה במעט בתוך החלון, הערך המקסימלי בחלון עדיין נשאר זהה לרוב, כך שהפלט לא משתנה משינויים קטנים במיקום.
