‏📋 הגדרה

‏שיטת למידה מונחית לבעיות סיווג (Classification), בעיקר בינארי, החוזה את ההסתברות שדגימה משתייכת למחלקה מסוימת, על ידי העברת קומבינציה לינארית של הפיצ'רים בפונקציית Sigmoid.

‏⚙️ איך זה עובד

  • ‏1. מחשבים קומבינציה לינארית של הפיצ'רים: z = β0 + β1x1 + ... + βnxn (בדיוק כמו ב-Linear Regression).
  • ‏2. מעבירים את z בפונקציית Sigmoid (Logistic) כדי לקבל הסתברות בין 0 ל-1.
  • ‏3. קובעים סף הכרעה (Threshold, בדרך כלל 0.5): מעל הסף → מחלקה 1, מתחת → מחלקה 0.
  • ‏4. מאמנים את המקדמים β על ידי מקסום ה-Likelihood (כלומר מינימום פונקציית ה-Log Loss) באמצעות Gradient Descent.

‏📐 נוסחאות

‏קומבינציה לינארית

z=β_0+β_1x_1+…+β_nx_n

‏Sigmoid (Logistic Function)

φ(z)=(1)/(1+e^{-z})

‏פונקציית עלות — Log Loss / Binary Cross-Entropy

J(β)=-(1)/(n)∑_{i=1}^n[y_ilog(ŷ_i)+(1-y_i)log(1-ŷ_i)]

‏Accuracy (מתוך Confusion Matrix)

Accuracy=(TP+TN)/(TP+TN+FP+FN)

‏Misclassification Rate

Error=(FP+FN)/(TP+TN+FP+FN)

‏🎯 שימושים עיקריים

  • ‏סיווג ספאם מול דואר לגיטימי (Spam vs. Ham).
  • ‏חיזוי כשל בהחזר הלוואה (Loan Default — כן/לא).
  • ‏אבחון מחלות (חולה/לא חולה) וכל בעיית סיווג בינארי אחרת.

‏✅ יתרונות

  • ‏פשוט, מהיר לאימון ופרשני — המקדמים מתורגמים ל-log-odds.
  • ‏מחזיר הסתברות (לא רק תווית), שמאפשרת קביעת סף לפי הצורך.
  • ‏עובד טוב כ-baseline חזק לבעיות סיווג בינארי.

‏❌ חסרונות / מגבלות

  • ‏מניח גבול הכרעה (Decision Boundary) לינארי בין המחלקות.
  • ‏רגיש למשתנים בלתי-תלויים מתואמים ביניהם (Multicollinearity).
  • ‏פחות מתאים למבני נתונים מורכבים/לא-לינאריים בהשוואה למודלים כמו עצים או רשתות נוירונים.

‏🧠 שאלות ראיון נפוצות

ש: ‏למה לא להשתמש ב-Linear Regression לבעיית סיווג בינארי?

ת: ‏כי היא יכולה להחזיר ערכים מתחת ל-0 או מעל 1, שאינם הסתברויות תקפות, ואין לה גבול הכרעה מובנה. פונקציית ה-Sigmoid פותרת זאת על ידי "דחיסת" הפלט לטווח [0,1].

ש: ‏מה ההבדל בין Accuracy ל-Misclassification Rate?

ת: ‏Accuracy = (TP+TN)/Total מודדת כמה פעמים המודל צדק; Misclassification Rate = (FP+FN)/Total מודדת כמה פעמים טעה. שתיהן משלימות ל-1.

ש: ‏מה עושה ה-Threshold של 0.5, ולמה לפעמים משנים אותו?

ת: ‏ה-Threshold קובע מאיזו הסתברות ומעלה מסווגים לדגימה כ-Class 1. משנים אותו (למשל ל-0.3) כשעלות False Negative גבוהה מ-False Positive, כמו באבחון מחלות.
