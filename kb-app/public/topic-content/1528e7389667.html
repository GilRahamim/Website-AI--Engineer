📋 הגדרה

ReAct (Reasoning + Acting) הוא framework המאפשר ל-LLM לא רק לייצר תשובות, אלא גם להחליט מתי לבצע פעולה (כגון שאילתה ל-retriever) ולחשוב צעד-אחר-צעד. בשילוב עם RAG, המודל יכול לשלב חשיבה, קריאה לכלים (tools), והטמעת ידע משוּלף באמצע תהליך החשיבה.

🏛️ איך זה עובד

  • ה-LLM מקבל prompt עם שאלה וממשק פעולות (כגון "Search", "Lookup").
  • ה-LLM מחליט, לפי חשיבה, האם לבצע retrieval.
  • מסמכים שנשלפו מוזרקים בחזרה לתוך ה-prompt באמצע השרשרת (mid-chain).
  • ה-LLM מייצר תשובה סופית המעוגנת בעדות חיצונית.
  • מומש לרוב באמצעות LangChain AgentExecutor עם retriever tool.

🎯 תחומי שימוש

  • שאילתות הדורשות החלטה על שימוש בכלים (tool-use decision-making).
  • שאילתות מורכבות/multi-hop הדורשות חשיבה על פני עובדות מרובות.
  • מקרים בהם לא בטוח אם retrieval חיצוני נדרש כלל.

✅ יתרונות

  • משלב חשיבה (reasoning) עם פעולה (acting) — גמיש יותר מ-RAG סטטי.
  • יכול להחליט באופן דינמי האם ומתי לשלוף ידע חיצוני.

❌ מגבלות

  • Latency גבוהה — חשיבה איטרטיבית ולעיתים קריאות מרובות לכלים.
  • עלות גבוהה — קריאות LLM ו-retriever מרובות לכל שאילתה.
  • לא מתאים למשימות פשוטות/שאילתות עובדתיות ישירות, או מקרים שבהם אי אפשר לשלם על קריאות מודל מרובות.

from langchain.tools.retriever import create_retriever_tool
from langchain_community.vectorstores import FAISS
from langchain_community.embeddings import HuggingFaceEmbeddings
from langchain_openai import ChatOpenAI

retriever = vectorstore.as_retriever()
retriever_tool = create_retriever_tool(
retriever=retriever,
name=&quot;insight_search&quot;,
description=&quot;Searches the document base for medical and pricing information.&quot;
)
llm = ChatOpenAI(temperature=0.3, model_name=&quot;gpt-3.5-turbo&quot;)
agent = initialize_agent(tools=[retriever_tool], llm=llm,
agent=AgentType.OPENAI_FUNCTIONS, verbose=True)
response = agent.run(&quot;What are the new insulin pricing changes announced in 2023?&quot;)

🧠 שאלות ראיון נפוצות

ש: מה ההבדל המהותי בין RAG רגיל ל-ReAct + RAG?

ת: ב-RAG רגיל ה-retrieval מתבצע תמיד באופן קבוע; ב-ReAct + RAG ה-LLM מחליט דינמית, מתוך חשיבה, מתי ואם בכלל לבצע retrieval, ויכול לשלב מספר קריאות tool במהלך תהליך החשיבה.

ש: מתי ReAct + RAG לא משתלם?

ת: במשימות פשוטות עם שאלות עובדתיות ישירות, או כשתקציב ה-latency/עלות לא מאפשר קריאות LLM ו-retriever מרובות.
