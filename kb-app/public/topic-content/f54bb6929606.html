📋 הגדרה

מבנה הנתונים הבסיסי בלמידה עמוקה — מערך רב-מימדי של מספרים (הכללה של סקלר, וקטור ומטריצה למימדים גבוהים יותר), המשמש לאחסון קלט, משקלים, אקטיבציות וגרדיאנטים בכל שלב של הרשת.

📐 מבנה ומימדים

  • סקלר (0-D Tensor) — מספר בודד, לדוגמה ערך Loss יחיד.
  • וקטור (1-D Tensor) — מערך חד-מימדי, לדוגמה embedding של מילה אחת.
  • מטריצה (2-D Tensor) — לדוגמה batch של דוגמאות עם תכונות, או משקלי שכבת Linear.
  • טנזור רב-מימדי (3-D ומעלה) — לדוגמה batch של תמונות בגודל [batch, channels, height, width].

🔑 תכונות מרכזיות

  • Shape — צורת הטנזור (גודל בכל מימד), לדוגמה [32, 3, 224, 224].
  • dtype — סוג הנתונים (float32, int64 וכו').
  • Device — היכן הטנזור מאוחסן בפועל (CPU או GPU/CUDA).
  • requires_grad — דגל הקובע אם יש לעקוב אחר היסטוריית הפעולות לצורך Autograd.

🎯 שימושים עיקריים

  • ייצוג קלט (תמונות, טקסט מקודד, אודיו) כמערכי מספרים.
  • ייצוג משקלי הרשת (W, b) בכל שכבה.
  • ייצוג אקטיבציות (פלטי ביניים) וגרדיאנטים בזמן אימון.

💻 קוד לדוגמה

import torch

x = torch.randn(32, 3, 224, 224)   # batch של 32 תמונות RGB בגודל 224x224
print(x.shape)    # torch.Size([32, 3, 224, 224])
print(x.dtype)    # torch.float32
print(x.device)   # cpu (או cuda:0 על GPU)

x = x.to(&quot;cuda&quot;)  # מעבירים את הטנזור ל-GPU

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין טנזור למטריצה?

ת: מטריצה היא מקרה פרטי של טנזור במימד 2; טנזור הוא הכללה למספר מימדים כלשהו (0,1,2,3,...), ומאפשר לייצג מבני נתונים מורכבים יותר כגון batch של תמונות צבעוניות.

ש: מה התפקיד של dtype ו-device בטנזור, ולמה הם חשובים בפרקטיקה?

ת: dtype קובע את דיוק החישוב (לדוגמה float32 לעומת float16) ומשפיע על מהירות וזיכרון; device קובע אם הטנזור מאוחסן ב-CPU או GPU — פעולות בין טנזורים חייבות להיות על אותו device, אחרת תתקבל שגיאה.
