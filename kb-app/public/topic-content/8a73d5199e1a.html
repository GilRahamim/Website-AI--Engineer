📋 הגדרה

Query Rewrite היא טכניקת עיבוד-מקדים (pre-retrieval) שבה LLM מנסח מחדש שאילתת משתמש מעורפלת או חלקית, כך שתהיה ספציפית וברורה יותר לפני ביצוע ה-retrieval — היא לא RAG בעצמה, אלא שלב המשפר את איכות ה-retrieval.

🔍 מתי זה קורה?

  • שאילתות מעורפלות (לדוגמה: "מה קרה עם האינסולין?").
  • שאילתות קצרות או חסרות הקשר.
  • סוכנים שיחתיים (conversational agents).
  • מקרים שבהם retrieval ראשוני נכשל.

⚠️ איך זה עובד

  1. המשתמש מקליד שאילתה.
  2. השאילתה מנוסחת מחדש על ידי LLM.
  3. השאילתה המנוסחת-מחדש משמשת לחיפוש דמיון וקטורי.
  4. ה-chunks שנשלפו מוזרקים ל-prompt ליצירת התשובה.

🛠️ מתי להשתמש / מתי להימנע

  • להשתמש: פורטלי חיפוש ארגוניים, בוטים בריאות/פיננסים עם שאלות חלקיות, אחזור משפטי/compliance.
  • להימנע: שאילתות שכבר מנוסחות היטב וספציפיות לדומיין, או מערכות עם דרישת latency קשיחה (real-time).

💰 השפעת latency ועלות

היבטהשפעה
Latencyבינונית — מוסיף קריאת LLM אחת לפני ה-retrieval
עלותמעט גבוהה יותר עקב קריאת LLM נוספת

🔄 קשר לנושאים אחרים

Query Rewrite משתלב כשלב מקדים לכל וריאנט RAG אחר — Conversational RAG, Multi-hop Retrieval וכו' — ומשפר את הקלט לפני שמתבצע חיפוש סמנטי.

💻 קוד לדוגמה

from langchain_openai import OpenAI
from langchain.prompts import PromptTemplate
def rewrite_query(original_query: str) -&gt; str:
llm = OpenAI(temperature=0.3)
prompt = PromptTemplate.from_template(
&quot;Rewrite the following question for better retrieval: {query}&quot;
)
return llm(prompt.format(query=original_query))
# Example:
# Input:  &quot;What happened with insulin?&quot;
# Output: &quot;What was the outcome of insulin [pricing policy]?&quot;

🧠 שאלות ראיון נפוצות

ש: מתי Query Rewrite לא משתלם?

ת: כשהשאילתות כבר ספציפיות וברורות, או כשתקציב ה-latency קשיח (למשל מערכות real-time) — הקריאה הנוספת ל-LLM לא מצדיקה את העלות.

ש: מה ההבדל בין Query Rewrite ל-Conversational RAG?

ת: Query Rewrite משנה ניסוח שאילתה בודדת לשיפור retrieval; Conversational RAG משתמש בהיסטוריית שיחה שלמה כדי להבין הקשר רב-תורי.
