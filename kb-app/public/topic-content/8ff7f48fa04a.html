📋 הגדרה

Claude Agent SDK (שינוי שם מ-Claude Code SDK, סוף 2025) הוא ספרייה (Python/TypeScript) שחושפת את אותו runtime שמפעיל את Claude Code — agent loop, כלים מובנים, skills, sub-agents, hooks, MCP — לשימוש headless מתוך סקריפטים, שירותים, או CI, ולא רק מטרמינל אינטראקטיבי.

🏛️ מבנה הארכיטקטורה

  • query() — לולאת ה-agent: לחשוב (reason), לקרוא לכלי (call tool), לצפות בתוצאה (observe), לחזור.
  • Options (ClaudeAgentOptions) — system prompt, כלים מורשים, MCP servers, תיקיות skills, hooks, permission mode, working directory.
  • כלים מובנים (in-box): Bash, Read, Write, Edit, Grep, Glob, WebFetch, Task (לקריאה ל-sub-agent), TodoWrite.
  • סטרימינג של הודעות מטיפוסים שונים: user, assistant, tool_use, tool_result, אירועי system — האפליקציה מחליטה מה לרנדר/לשמור.
  • קומפוזביליות: Skills מזינות נהלים, MCP מזין כלים, hooks מזינים חוקים, sub-agents מזינים בידוד קונטקסט — ה-SDK מחבר את כולם.

💻 קוד לדוגמה — Agent מינימלי

# pip install claude-agent-sdk
import anyio
from claude_agent_sdk import query, ClaudeAgentOptions
options = ClaudeAgentOptions(
model='claude-sonnet-4-6',
system_prompt='You are a senior Python reviewer.',
allowed_tools=['Read', 'Grep', 'Glob'],
permission_mode='acceptEdits',
cwd='/repo',
)
async def main():
async for msg in query(
prompt='Review src/auth.py for security issues.',
options=options,
):
print(msg)
anyio.run(main)

🎯 מתי להשתמש ב-SDK

  • צריך agent מתוך סקריפט, שירות (service), או job ב-CI.
  • רוצים את הפרימיטיבים של Claude Code (skills, sub-agents, hooks, MCP) — בלי טרמינל אינטראקטיבי.

✅ יתרונות

  • חוסך כתיבת agent loop, ניהול כלים, וניהול קונטקסט מאפס (לעומת Raw API).
  • אותו runtime בדיוק כמו Claude Code — תאימות מלאה ל-skills/sub-agents/hooks/plugins.
  • תמיכה ב-Python ו-TypeScript; סטרימינג של אירועים טיפוסיים.

❌ מגבלות

  • פחות שליטה גרעינית (low-level) מ-Raw API למי שצריך לולאת agent מאוד מותאמת-אישית.
  • תלוי בריצה headless — לא מספק את חוויית ה-IDE/CLI האינטראקטיבית של Claude Code עצמו.

🧠 שאלות ראיון נפוצות

ש: מה ההבדל המעשי בין Claude Agent SDK ל-Raw API?

ת: Raw API נותן קריאת מודל בודדת — אתם כותבים את לולאת ה-agent, ניהול כלים, וקונטקסט בעצמכם. Agent SDK מספק query() עם לולאת agent מובנית, כלים מוכנים (Bash/Read/Edit וכו'), ותמיכה ב-skills/sub-agents/hooks/MCP — אותו runtime שמפעיל את Claude Code, אך headless.

ש: מתי תבחרו ב-Claude Code על פני Agent SDK?

ת: כשהמשתמש עובד אינטראקטיבית בטרמינל/IDE וצריך session-driven workflow עם פידבק מיידי; Agent SDK מתאים יותר לשירותים headless, אוטומציה ב-CI, או הטמעה בתוך אפליקציה/סקריפט משלכם.
