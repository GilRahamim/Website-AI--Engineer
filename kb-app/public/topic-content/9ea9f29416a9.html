📋 הגדרה

Computer Vision כולל כמה סוגי משימות בסיסיים שמטרתם לחלץ מידע שונה מתמונה — מ'מה יש בתמונה' (classification) ועד 'אילו פיקסלים בדיוק שייכים לאובייקט' (segmentation). YOLO מספק מודלים נפרדים (אך ארכיטקטורה דומה) לכל אחת מהמשימות.

🔍 ארבעת סוגי המשימות העיקריים

משימהתפוקה
Classificationתווית (label) אחת לכל התמונה (לדוגמה: Dog, Car, Pizza)
Detection (Localization)Bounding box + תווית + ביטחון לכל אובייקט בתמונה

💻 Pose Estimation — קוד וזרימה

המודל חוזה מיקום אדם וקואורדינטות keypoints, מחבר ביניהן (skeleton), ומאפשר הבנת תנוחה ותנועה. שימושים: fitness tracking, ניתוח ספורט, הכרת תנועות (gesture recognition), מעקב תנועה.
# 04_pose_estimation.py
results = model(frame)  # model = YOLO(&quot;yolov8s-pose.pt&quot;)
keypoints = results[0].keypoints  # nose, eyes, shoulders, elbows, wrists, knees, ankles

🎯 שימושים עיקריים לפי סוג משימה

  • Classification: מיון תמונות, autonomous driving, הדמיה רפואית.
  • Detection: זיהוי בזמן אמת, ספירת אנשים, אבטחה.
  • Segmentation: נהיגה אוטונומית, רפואה, רובוטיקה — כשצורה מדויקת קריטית.
  • Pose Estimation: fitness, ספורט, gesture recognition.

🧠 שאלות ראיון נפוצות

ש: מתי תבחרו segmentation על פני detection פשוט, חרף העלות החישובית הגבוהה יותר?

ת: כשצורת האובייקט המדויקת קריטית למשימה — לדוגמה ברפואה (גבולות גידול מדויקים) או בנהיגה אוטונומית (הבחנה בין מדרכה לכביש בפיקסל). אם רק 'איפה האובייקט בערך' מספיק (כמו ספירת אנשים), detection מהיר יותר ומספיק.

ש: איך pose estimation 'בונה' על detection במקום להיות משימה נפרדת לחלוטין?

ת: המודל מזהה תחילה את מיקום האדם (כמו detection רגיל), ואז מוסיף שכבת חיזוי נוספת לקואורדינטות ה-keypoints על גבי אותו אזור — כך שהוא משתמש בעיקרון 'לוקח את ה-bounding box ומעמיק אותו' במקום לפתור מבעיה אחרת.
