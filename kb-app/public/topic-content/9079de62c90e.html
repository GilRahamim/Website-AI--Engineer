הגדרה

יחידת החישוב הבסיסית ברשתות נוירונים: מקבלת מספר כניסות, מחשבת שקלול לינארי שלהן בתוספת bias, ומעבירה את התוצאה דרך פונקציית activation. בשנות ה-50 קראו לזה ``פרספטרון''; כשזה הפך לדימוי למוח האנושי עברו לקרוא לזה ``נוירון''. שני השמות מתייחסים לאותו דבר.

מבנה

  • כניסות x₁…xₙ — הפיצ'רים של התצפית. הם אינם נוירונים: לא מתבצעת בהם פעולה חישובית, הם רק מחזיקים את ערכי הכניסה.
  • משקולות w₁…wₙ — הפרמטרים שהמכונה לומדת.
  • Bias b — פרמטר נוסף אחד שמאפשר לנוירון להזיז את סף ההפעלה ולא להיות כבול לאפס.
  • פעולה 1 — טרנספורמציה לינארית: סכימה משוקללת של הכניסות.
  • פעולה 2 — פונקציית Activation שמכניסה אי-לינאריות.

זה כל מה שנוירון עושה. המורכבות של הרשת כולה נובעת מחיבור הרבה נוירונים יחד, לא מהמורכבות של נוירון בודד.

נוסחאות מפתח

במונחים וקטוריים, עבור batch שלם:

רגרסיה לוגיסטית היא פרספטרון אחד

רגרסיה לוגיסטית היא בדיוק נוירון בודד עם Sigmoid כפונקציית activation: הנוירון מחשב את הטרנספורמציה הלינארית a, וה-Sigmoid ממירה אותה להסתברות בין 0 ל-1. לכן פרספטרון עם BCE loss ו-Sigmoid ב-PyTorch נותן תוצאות כמעט זהות ל-LogisticRegression של Scikit-Learn.

יתרונות

  • פשוט להבנה ולמימוש — אבן הבניין של כל רשת עמוקה.
  • מהיר וזול חישובית.
  • גשר מושגי מרגרסיה לוגיסטית לרשתות נוירונים.

מגבלות

  • התועלת של פרספטרון בודד מוגבלת — הוא מפריד רק בצורה לינארית.
  • אינו יכול לפתור בעיות שאינן ניתנות להפרדה לינארית (XOR הקלאסי).
  • הפתרון: לסדר נוירונים רבים בשכבות — כך מגיעים ל-MLP.

import torch.nn as nn

# פרספטרון בודד לסיווג בינארי = רגרסיה לוגיסטית
perceptron = nn.Sequential(
    nn.Linear(in_features=n_features, out_features=1),   # a = b + sum(w*x)
    nn.Sigmoid()                                          # y = g(a)
)
criterion = nn.BCELoss()

# מימוש מפורש של אותו דבר
class Perceptron(nn.Module):
    def __init__(self, n_features):
        super().__init__()
        self.linear = nn.Linear(n_features, 1)
        self.activation = nn.Sigmoid()

    def forward(self, x):
        return self.activation(self.linear(x))

שאלות ראיון נפוצות

ש: האם הכניסות x נחשבות נוירונים?

ת: לא. שכבת הכניסה רק מחזיקה את ערכי הפיצ'רים ולא מבצעת חישוב. נוירון מוגדר כיחידה שמבצעת חישוב — טרנספורמציה לינארית ואחריה activation. בציורים מסמנים לפעמים גם את הכניסות כעיגולים, וזה מבלבל.

ש: לכל נוירון יש loss function משלו?

ת: לא. Loss function יש אחד לכל הרשת, והוא מחושב רק אחרי שהתצפית עברה דרך כל הרשת. פונקציית ה-activation לעומת זאת נמצאת בתוך כל נוירון. ה-loss הוא חיצוני לרשת — הוא מודד את המרחק בין החיזוי לתשובה.

ש: למה צריך Bias?

ת: בלי b, ההיפר-מישור שהנוירון מגדיר חייב לעבור דרך הראשית. ה-bias מאפשר להזיז אותו במרחב, כלומר לשלוט בסף ההפעלה של הנוירון באופן בלתי תלוי בערכי הכניסה.
