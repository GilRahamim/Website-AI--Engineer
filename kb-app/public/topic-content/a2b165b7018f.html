הגדרה

אלגוריתם האופטימיזציה שעליו בנויה כל למידת המכונה המודרנית: במקום לסרוק את כל מרחב הפרמטרים, מחשבים את הגרדיאנט של פונקציית ה-Loss ביחס לכל פרמטר ומזיזים את הפרמטרים צעד קטן בכיוון ההפוך לגרדיאנט — הכיוון שבו ה-Loss יורד הכי מהר.

איך זה עובד

  • 1. מאתחלים את הפרמטרים θ בערכים אקראיים.
  • 2. מריצים forward pass ומחשבים את ה-Loss על הדאטה.
  • 3. מחשבים את הנגזרת החלקית של ה-Loss ביחס לכל פרמטר — ∂L/∂θᵢ. הנגזרת אומרת איך ה-Loss מגיב לשינוי באותו פרמטר.
  • 4. אם הנגזרת חיובית — ה-Loss גדל כשהפרמטר גדל, ולכן מקטינים את הפרמטר; אם היא שלילית — מגדילים אותו.
  • 5. מעדכנים כל פרמטר בגודל פרופורציונלי לנגזרת ולקצב הלמידה α.
  • 6. חוזרים עד שמתקיים תנאי עצירה — מספר איטרציות, יעד Loss או התכנסות.

שימושים עיקריים

  • אימון כל רשת נוירונים — מ-Perceptron בודד ועד Transformer.
  • רגרסיה לינארית ולוגיסטית כאשר Normal Equation יקרה מדי חישובית.
  • כל בעיה שבה פונקציית המטרה גזירה ביחס לפרמטרים.

יתרונות

  • דגימה דלילה מאוד של מרחב הפרמטרים — לא צריך לסרוק את כולו.
  • מסתדר עם מיליוני פרמטרים, שם Complete Enumeration קורסת.
  • אדפטיבי — אפשר לשנות את גודל הצעד לאורך כל ציר בנפרד (זה בדיוק מה ש-AdaGrad ו-Adam עושים).

חסרונות / מגבלות

  • עלול להיתקע במינימום לוקאלי או בנקודת אוכף.
  • רגיש לבחירת α — צעד גדול מדי גורם ל-overshooting והתבדרות, צעד קטן מדי גורם להתכנסות איטית מאוד.
  • דורש שפונקציית ה-Loss תהיה גזירה.
  • הגרדיאנט הנומרי אינו מדויק ויקר — ולכן בפועל תמיד autograd.

קוד לדוגמה (PyTorch)

import torch

# הפרמטרים שנלמדים
w = torch.tensor([0.5], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)
lr = 0.01

for step in range(100):
    y_pred = w * x + b
    loss = ((y_pred - y) ** 2).mean()      # MSE

    loss.backward()                        # autograd -> w.grad, b.grad
    with torch.no_grad():
        w -= lr * w.grad                   # theta := theta - alpha * grad
        b -= lr * b.grad
    w.grad.zero_(); b.grad.zero_()         # אחרת הגרדיאנטים מצטברים

# בפועל משתמשים ב-optimizer שעושה בדיוק את זה:
optimizer = torch.optim.SGD([w, b], lr=lr)
optimizer.step(); optimizer.zero_grad()

שאלות ראיון נפוצות

ש: למה לא פשוט סורקים את כל מרחב הפרמטרים במקום Gradient Descent?

ת: כי הסקיילינג הוא xⁿ עם n מספר הפרמטרים. לרשת עם מיליון פרמטרים זה בלתי אפשרי. Gradient Descent דוגם את המרחב בצורה דלילה מאוד ועדיין מתכנס, כי הגרדיאנט אומר לנו לאן ללכת.

ש: מה ההבדל בין גרדיאנט נומרי לאנליטי?

ת: נומרי מקרב את הנגזרת בהפרש סופי עם Δ קטן — לא מדויק ודורש שתי הערכות מודל לכל פרמטר. אנליטי גוזר את הפונקציה עצמה בעזרת כלל השרשרת — מדויק וזול. Autograd מבצע את החישוב האנליטי אוטומטית דרך הגרף החישובי.

ש: למה צריך zero_grad() בכל איטרציה?

ת: PyTorch צובר גרדיאנטים ב-.grad במקום לדרוס אותם. בלי איפוס, העדכון באיטרציה הנוכחית יתבסס על סכום כל הגרדיאנטים מכל האיטרציות הקודמות.
