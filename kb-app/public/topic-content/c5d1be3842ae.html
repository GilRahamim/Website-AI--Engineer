📋 הגדרה

Sub-agent הוא agent עזר עם חלון קונטקסט נקי משלו, כלים משלו, ו-system prompt משלו, שנקרא על ידי agent הורה (parent) באמצעות כלי ה-Task — ומחזיר סיכום (summary) בלבד להורה, כדי למנוע 'זיהום' קונטקסט בריצות ארוכות.

🔍 הבעיה שזה פותר

ריצות agent ארוכות מזהמות את הקונטקסט: תוצאות כלים ישנות (stale tool results), תוכניות מיושנות, וענפים מתים (dead branches) — כולם נשארים בחלון הקונטקסט ומפריעים להחלטות עתידיות.

🎯 מקרי שימוש

  • מחקר מקבילי (parallel research) — פתיחת 5 sub-agents במקביל, מיזוג ממצאים.
  • קריאות כבדות (heavy reads) — sub-agent עושה grep/read על עץ קבצים גדול, מחזיר פסקה אחת.
  • תפקידי מומחה (specialist roles) — reviewer, planner, executor.

⚙️ איך מגדירים Sub-Agent

מוגדר כקובץ markdown בנתיב .claude/agents/*.md עם YAML frontmatter: name, description, tools, model. ה-agent ההורה רואה את הקובץ וקורא לו דרך כלי ה-Task כשה-description תואם את המשימה.

💻 קוד לדוגמה — הגדרת Sub-Agent

# .claude/agents/security-reviewer.md
---
name: security-reviewer
description: Reviews code for OWASP-style issues. Use when the user
asks for a security review or before merging auth code.
tools: [Read, Grep, Glob]
model: claude-opus-4-7
---
# Security Reviewer
You are a paranoid security reviewer. Focus on:
- Injection (SQL, command, path)
- Authn/authz gaps
- Secret handling
- Unsafe deserialization
Return a punch list. Cite file:line. Under 200 words.

🛠️ איך פותרים / מטפלים (anti-pattern נפוץ)

  • אנטי-פטרן: לדחוס הכול ל-agent הראשי — הקונטקסט מתנפח (bloats) והמודל סוטה (drifts). הפתרון: לדחוף עבודת מומחה (specialist work) ל-sub-agents.
  • Fan-out research: פתיחת N sub-agents במקביל, מיזוג סיכומים — חוסך קונטקסט וזמן-קיר (wall time).

🔄 קשר לנושאים אחרים

Sub-agents הם רכיב בתוך Claude Agent SDK Architecture (מסמך 56), ומשתלבים עם Hooks (מסמך 58) ו-Plugins (מסמך 59) בבניית workflows מלאים — לדוגמה demo ה-code-review plugin.

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין sub-agent ל-multi-agent (CrewAI/Agent כללי)?

ת: sub-agent ב-Claude Agent SDK הוא מנגנון בידוד קונטקסט בתוך ריצה אחת של agent הורה — נקרא דרך כלי Task, מחזיר סיכום, וייעודו בעיקר טכני (ניהול זיכרון/קונטקסט). Multi-agent (כמו ב-CrewAI) הוא דגם ארכיטקטוני רחב יותר של אורקסטרציה בין agents עצמאיים עם תפקידים מוגדרים, ולא רק כלי לניהול קונטקסט.

ש: מדוע sub-agent 'heavy reads' מחזיר פסקה אחת בלבד ולא את כל הקובץ?

ת: כדי שהקונטקסט של ה-agent ההורה יישאר נקי — אם ה-sub-agent יחזיר את כל תוכן הקריאה הכבדה, המטרה (חיסכון בקונטקסט) מתבטלת; הוא מסכם רק את התובנה הרלוונטית.
