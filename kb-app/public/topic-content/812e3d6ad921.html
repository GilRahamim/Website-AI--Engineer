📋 הגדרה

Skill הוא תיקייה ארוזה של הוראות, סקריפטים וקבצי-עזר ש-Claude טוען לפי-דרישה כאשר המשימה מתאימה. ניתן לחשוב עליו כ"ספר-משחק" מתמחה: Claude קורא את SKILL.md, מגלה אילו כלים/קבצים זמינים, ועוקב אחר התהליך המתועד. העיקרון המרכזי: model-invoked, לא protocol-invoked — Claude עצמו מחליט מתי להפעיל Skill לפי התיאור שלו, ללא חיווט (wiring) או שרתים.

🏛️ אנטומיה של Skill

  • SKILL.md (חובה) — YAML frontmatter עם name ו-description (לצורך התאמת הפעלה), וגוף markdown עם הוראות ש-Claude קורא כשה-Skill נטען.
  • scripts/ — עזרים הרצים (Python, Bash, Node).
  • references/ — מסמכים ארוכים ש-Claude קורא רק לפי צורך.
  • templates/, assets/ — תבניות, תמונות, דוגמאות.

⚙️ Progressive Disclosure — טעינה בשלושה שלבים

שלבמה נטעןמתי
Tier 1name + description בלבד מכל Skillתמיד טעון
Tier 2גוף ה-SKILL.mdבעת הפעלה (כשהמשימה תואמת)
Tier 3scripts/, references/לפי דרישה, רק כשנדרש

התוצאה: עשרות Skills יכולים להתקיים יחד בעומס token מינימלי — Claude מביא לתוך ה-context רק את הפרוצדורה הרלוונטית למשימה הנוכחית. בניגוד לכלי MCP — שבהם כל סכמת tool נטענת מראש, יתרון לקריאת-כלים מסוג typed אך עלות גבוהה כשיש מאות כלים.

💻 קוד לדוגמה — SKILL.md

---
name: pdf-extractor
description: Extracts structured text and tables from PDF files.
Use when the user asks to read, parse, or summarize a PDF.
---
# PDF Extractor Skill
## When to use
Activate when the user provides a .pdf path and asks for its content,
tables, or a summary.
## How to run
1. Call scripts/extract.py with the PDF path.
2. If extraction yields no text, fall back to scripts/ocr.py.
3. Format the output using templates/report.md.

💻 קוד לדוגמה — הפעלת Skill מתוך Agent SDK

from anthropic import Anthropic
from pathlib import Path
client = Anthropic()
skill_dir = Path(__file__).parent / &quot;stock-report&quot;
skill_md = (skill_dir / &quot;SKILL.md&quot;).read_text()
resp = client.messages.create(
model=&quot;claude-sonnet-4-6&quot;, max_tokens=2048,
system=f&quot;You have access to this Skill:\n\n{skill_md}&quot;,
tools=[{&quot;type&quot;: &quot;bash_20250124&quot;, &quot;name&quot;: &quot;bash&quot;}],
messages=[{&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;Give me a stock report for NVDA.&quot;}],
)
print(resp.content[-1].text)

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין 'model-invoked' ל-'protocol-invoked'?

ת: Skill הוא model-invoked — Claude עצמו מחליט מתי להפעיל אותו, על סמך התאמת ה-description למשימה, ללא צורך בחיווט חיצוני. כלי MCP הם protocol-invoked — הפעלתם מתבססת על סכמת tool מוגדרת-מראש שנטענת ונקראת באופן מבני.

ש: מה היתרון המרכזי של progressive disclosure?

ת: מאפשר לעשרות Skills להתקיים יחד בעומס טוקנים מינימלי — רק השם וה-description תמיד בזיכרון, וגוף ההוראות/קבצי העזר נטענים רק כשה-Skill בפועל מופעל.
