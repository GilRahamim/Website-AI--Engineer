📋 הגדרה

ארכיטקטורה כללית למיפוי רצף קלט לרצף פלט באורך שונה, המורכבת משני רכיבים: Encoder שמקודד את הקלט לייצוג קבוע, ו-Decoder שמייצר את הפלט צעד-צעד מתוך ייצוג זה.

🏛️ מבנה הרשת

  • Encoder — רשת (RNN/LSTM/Transformer) הקוראת את כל רצף הקלט ומפיקה ייצוג סיכום (Context Vector) או רצף מצבים חבויים
  • Context Vector — "גשר המידע" בין ה-Encoder ל-Decoder
  • Decoder — רשת אוטורגרסיבית המייצרת את רצף הפלט מילה-מילה, מותנית בייצוג ה-Encoder ובמילים שכבר נוצרו
  • מנגנון Attention (אופציונלי אך נפוץ) — מאפשר ל-Decoder "להביט" בכל מצבי ה-Encoder ולא רק בווקטור יחיד

📐 נוסחאות מפתח

🎯 תחומי שימוש

  • תרגום מכונה (Machine Translation)
  • סיכום טקסט (Text Summarization)
  • כיתוב תמונות (Image Captioning) — Encoder על תמונה, Decoder טקסטואלי
  • זיהוי דיבור והמרת דיבור לטקסט

✅ יתרונות

  • מטפל באופן טבעי במיפוי קלט-פלט באורכים שונים
  • ארכיטקטורה כללית — ה-Encoder/Decoder יכולים להיות RNN, LSTM או Transformer
  • בסיס למודלים מודרניים של יצירת טקסט וייצור שפה

❌ מגבלות

  • ה-Context Vector היחיד (בלי Attention) הוא Bottleneck מידעי לרצפים ארוכים
  • אימון סדרתי ב-Decoder (אוטורגרסיה) — איטי בזמן הסקה
  • רגיש ל-Exposure Bias — פער בין אימון (Teacher Forcing) להסקה

💻 קוד לדוגמה (PyTorch)

import torch.nn as nn

encoder = nn.LSTM(input_size=128, hidden_size=256, batch_first=True)
decoder = nn.LSTM(input_size=128, hidden_size=256, batch_first=True)

_, (h_n, c_n) = encoder(src)               # encode source sequence
dec_out, _ = decoder(tgt, (h_n, c_n))      # decode conditioned on encoder state

🧠 שאלות ראיון נפוצות

ש: מה הבעיה ב-Seq2Seq בלי Attention, ואיך Attention פותר אותה?

ת: כל המידע מהקלט נדחס לווקטור Context יחיד, שמהווה Bottleneck לרצפים ארוכים. Attention מאפשר ל-Decoder לגשת ישירות לכל מצבי ה-Encoder, וכך לשמר מידע טוב יותר.

ש: מה זה Exposure Bias ב-Seq2Seq?

ת: באימון משתמשים ב-Teacher Forcing (מזינים את הפלט האמיתי), אך בהסקה ה-Decoder מקבל את הפלט שהוא עצמו ייצר; טעויות מצטברות מהר יותר מהמצב שאומן עליו.
