📋 הגדרה

מנגנון שמאפשר ל-LLM להפעיל פונקציות/כלים חיצוניים (APIs, קוד, לוגיקה עסקית) על-ידי בניית קריאה מבנית (JSON) תואמת-סכמה, במקום רק להחזיר טקסט חופשי.

⚙️ איך זה עובד — חמשת השלבים

  1. User prompt — המשתמש שואל שאלה הדורשת מידע/פעולה חיצונית.
  2. LLM decides — המודל מזהה שצריך כלי, ובוחר את הפונקציה המתאימה מתוך הסכמות שהוגדרו.
  3. Fills parameters — המודל בונה אובייקט JSON תקין לפי schema (לדוגמה {"location": "London"}).
  4. Calls function — קוד האפליקציה (לא ה-LLM) מפעיל את הפונקציה האמיתית עם הפרמטרים.
  5. Returns structured output — התוצאה מוחזרת ל-LLM שמנסח תשובה בשפה טבעית למשתמש.

🧩 הגדרת כלי (Tool Definition)

כלי מוגדר בעיקר על-ידי שלושה שדות: name (שם הפונקציה), description (מה היא עושה — לטובת הבנת ה-LLM), ו-parameters (סכמת JSON Schema של הקלט).

💻 קוד לדוגמה (OpenAI tools schema)

tools = [{
&quot;type&quot;: &quot;function&quot;,
&quot;function&quot;: {
&quot;name&quot;: &quot;get_current_weather&quot;,
&quot;description&quot;: &quot;Get the current weather for a given location&quot;,
&quot;parameters&quot;: {
&quot;type&quot;: &quot;object&quot;,
&quot;properties&quot;: {
&quot;location&quot;: {&quot;type&quot;: &quot;string&quot;, &quot;description&quot;: &quot;City name&quot;}
},
&quot;required&quot;: [&quot;location&quot;]
}
}
}]
response = client.chat.completions.create(
model=&quot;gpt-4o&quot;, messages=messages, tools=tools, tool_choice=&quot;auto&quot;
)
tool_calls = response.choices[0].message.tool_calls

🛠️ דרכים להגדיר כלים

שיטהתיאור
JSON Schema ידניהגדרה מלאה ומפורשת של name/description/parameters
@tool decorator (OpenAI SDK / LangChain)עוטף פונקציית Python — type hints הופכים לסכמת פרמטרים, docstring הופך לתיאור

🎯 שימושים עיקריים

  • חיבור ל-APIs חיצוניים (מזג אוויר, מסדי נתונים, התראות).
  • בסיס לבניית Agents — ה-Agent הוא בעצם LLM עם גישה לכלים ולולאת תכנון/הפעלה.
  • אינטגרציה בטוחה עם לוגיקה עסקית — בלי לתת ל-LLM להריץ קוד חופשי.

🔄 קשר ל-LangChain Agents

LangChain בונה שכבת abstraction מעל function calling: Agent מקבל רשימת tools ומודל, ומחליט אוטונומית אילו כלים להפעיל ובאיזה סדר — בהשוואה לקריאת כלי בודד שמוגדרת מראש ב-prompt יחיד.

🧠 שאלות ראיון נפוצות

ש: מי בפועל 'מריץ' את הפונקציה — ה-LLM או קוד האפליקציה?

ת: קוד האפליקציה. ה-LLM רק מחזיר JSON עם שם הפונקציה והפרמטרים — לעולם לא מריץ קוד בפועל. זה מה שהופך את המנגנון לבטוח ובר-בקרה.

ש: מה ההבדל בין function calling רגיל לבין Agent שמשתמש בכלים?

ת: Function calling בודד הוא קריאה חד-שלבית: שאלה → בחירת כלי אחד → תשובה. Agent מוסיף לולאה: הוא יכול לקרוא לכמה כלים ברצף, להעריך תוצאות ביניים, ולתכנן את הצעד הבא — מעבר לקריאת כלי יחידה.
