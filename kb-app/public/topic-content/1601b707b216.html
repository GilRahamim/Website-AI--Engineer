📋 הגדרה

אלגוריתם לחישוב הגרדיאנט של פונקציית ה-Loss לגבי כל אחד ממשקלי הרשת, על ידי שימוש בכלל השרשרת (Chain Rule) ומעבר אחורה מהפלט לכניסה. הוא הבסיס לאימון כל רשת עצבית עמוקה.

⚙️ איך זה עובד

  1. מעבר קדימה (Forward Pass): מחשבים את הפלט של הרשת ואת ערך ה-Loss.
  2. שומרים את הערכים הביניים (activations) של כל שכבה במהלך המעבר הקדימה.
  3. מתחילים מהשכבה האחרונה ומחשבים את הגרדיאנט של ה-Loss לגבי הפלט.
  4. משתמשים בכלל השרשרת כדי להעביר את הגרדיאנט אחורה משכבה לשכבה.
  5. בכל שכבה מחשבים את הגרדיאנט לגבי המשקלים (W) וה-bias, ושומרים אותו.
  6. מעבירים את הגרדיאנט לשכבה הקודמת וחוזרים על השלב עד לשכבת הכניסה.
  7. מעדכנים את המשקלים בעזרת אלגוריתם אופטימיזציה (כגון SGD או Adam).

💻 קוד לדוגמה (Python / PyTorch)

import torch

x = torch.randn(4, 10, requires_grad=False)
y = torch.randn(4, 1)

model = torch.nn.Linear(10, 1)
loss_fn = torch.nn.MSELoss()

pred = model(x)
loss = loss_fn(pred, y)

loss.backward()        # Backpropagation - מחשב גרדיאנטים אוטומטית
print(model.weight.grad)  # הגרדיאנט שחושב

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין Forward Pass ל-Backward Pass?

ת: ב-Forward Pass מחשבים את הפלט והלוס תוך שמירת ערכי ביניים; ב-Backward Pass מפיצים את הגרדיאנט אחורה דרך השכבות בעזרת כלל השרשרת כדי לעדכן משקלים.

ש: מדוע Backpropagation סובל מ-Vanishing Gradients ברשתות עמוקות?

ת: כי הגרדיאנט מחושב כמכפלה של נגזרות רבות; אם כל נגזרת קטנה מ-1 (כמו ב-Sigmoid), המכפלה דועכת אקספוננציאלית עם העומק.
