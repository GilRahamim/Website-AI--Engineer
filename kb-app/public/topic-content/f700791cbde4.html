📋 הגדרה

שיטת אופטימיזציה המתאימה learning rate נפרד לכל פרמטר, על סמך סכום ריבועי הגרדיאנטים ההיסטוריים שלו — פרמטרים עם גרדיאנטים גדולים בעבר מקבלים learning rate קטן יותר, ולהפך.

⚙️ איך זה עובד

  1. מאתחלים מצבר ריבועי גרדיאנטים G=0 עבור כל פרמטר.
  2. בכל איטרציה מחשבים את הגרדיאנט g_t ומצרפים את ריבועו ל-G.
  3. מחשבים learning rate אפקטיבי לכל פרמטר: α מחולק בשורש G (פלוס אפסילון למניעת חילוק באפס).
  4. מעדכנים כל פרמטר ב-learning rate האפקטיבי שלו.

📐 נוסחאות

🎯 שימושים עיקריים

  • דאטה דליל (sparse), כגון NLP עם מילים נדירות — פרמטרים נדירים מקבלים עדכון גדול יותר כשהם כן מופיעים
  • בעיות שבהן תכונות שונות בסקאלות שונות מאוד

✅ יתרונות

  • מתאים learning rate אוטומטית לכל פרמטר בנפרד
  • עובד טוב מאוד עם דאטה דליל
  • אין צורך לכוון ידנית learning rate שונה לכל תכונה

❌ חסרונות / מגבלות

  • ה-learning rate האפקטיבי דועך באופן מונוטוני ועלול להפוך לקטן מאוד עד שהאימון "נתקע" (vanishing LR)
  • פחות מתאים לרשתות עמוקות לא-קונבקסיות בהשוואה ל-Adam

💻 קוד לדוגמה (Python / PyTorch)

import torch

model = torch.nn.Linear(10, 1)
optimizer = torch.optim.Adagrad(model.parameters(), lr=0.01)

for x_batch, y_batch in dataloader:
    optimizer.zero_grad()
    loss = torch.nn.functional.mse_loss(model(x_batch), y_batch)
    loss.backward()
    optimizer.step()   # G += grad^2 ; theta -= alpha/sqrt(G+eps) * grad

🧠 שאלות ראיון נפוצות

ש: מה החיסרון המרכזי של AdaGrad באימון ארוך?

ת: ה-G המצטבר רק גדל עם הזמן, כך שה-learning rate האפקטיבי דועך באופן מונוטוני ויכול להגיע לאפס בפועל לפני שהמודל התכנס.

ש: למה AdaGrad מתאים במיוחד ל-NLP?

ת: כי תכונות/מילים נדירות מקבלות גרדיאנטים גדולים לעיתים רחוקות, ו-AdaGrad משמר עבורן learning rate גבוה יחסית כשהן כן מופיעות.
