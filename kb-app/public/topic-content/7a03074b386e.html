🔒 טשטוש פנים ו-Privacy AI

המערכת מזהה אזורי פנים (מבוססת על keypoints מ-pose estimation), ומפעילה Gaussian blur להגנה על זהויות. שימושים: תאימות GDPR, מעקב חכם, אנליטיקס ציבורי, AI שמשמר פרטיות.

# 08_face_blur.py

def blur_face_region(frame, keypoints_xy):

"""Blur the face area estimated from pose keypoints."""

h, w = frame.shape[:2]

nose = keypoints_xy[NOSE_INDEX]

left_ear = keypoints_xy[LEFT_EAR_INDEX]

right_ear = keypoints_xy[RIGHT_EAR_INDEX]

cx, cy = int(nose[0]), int(nose[1])

x1 = max(0, cx - face_width // 2)

y1 = max(0, cy - face_height // 2)

x2 = min(w, cx + face_width // 2)

y2 = min(h, cy + face_height // 2)

if x2 > x1 and y2 > y1:

roi = frame[y1:y2, x1:x2]

blurred = cv2.GaussianBlur(roi, (99, 99), 30)

result = frame.copy()

result[y1:y2, x1:x2] = blurred

return result

return frame

🧠 שאלות ראיון נפוצות

ש: מדוע face blur בדמו זה מבוסס על pose keypoints (אף, אוזניים) ולא על face-detection ייעודי?

ת: כי המודל כבר מריץ pose estimation לצרכים אחרים (זיהוי גוף) — שימוש בקואורדינטות nose/ears הקיימות חוסך הרצת מודל נפרד לזיהוי פנים, ומספק הערכה 'מספיק טובה' לאזור הפנים לצורך blur, במחיר דיוק גיאומטרי מדויק פחות מ-face detector מיועד.

ש: מה ההבדל התשתיתי בין pipeline של static image detection ל-real-time webcam detection?

ת: ב-static image אין לולאת capture רציפה — תמונה בודדת נטענת, מורצת פעם אחת דרך המודל, והתוצאה נשמרת לקובץ (cv2.imwrite). ב-real-time יש לולאת capture-detect-display מתמשכת שמטרתה latency נמוך ו-FPS גבוה, ולא רק דיוק.
