📋 הגדרה

ייצוג של מסמך כווקטור ספירות — לכל מילה באוצר המילים, כמה פעמים היא מופיעה במסמך. השם 'שק מילים' מבטא את העיקרון המרכזי: סדר המילים נשמט לחלוטין, ונשמרת רק תדירות ההופעה.

🔍 מתי זה קורה? (מתי משתמשים)

  • כשלב ביניים בסיסי לפני שקלול TF-IDF, אימון Topic Modeling (LDA) או הזנת קלט לקלסיפייר.
  • כל פעם שצריך ייצוג מהיר וקל-לפענוח, ואין צורך ברגישות לסדר המילים.

⚙️ איך בונים ייצוג BoW

  • עיבוד מקדים (Preprocessing): הסרת סימני פיסוק.
  • Tokenization — פירוק הטקסט למילים בודדות.
  • בניית מילון (Dictionary) — הקצאת מזהה (id) לכל מילה שרוצים לשמור.
  • בניית וקטור BoW — ספירת מספר המופעים של כל מילה.

דוגמה: וקטור ה-BoW של מסמך מסוים יכול להיראות כך —

✅ יתרונות

  • מאפשר שימוש במדדי דמיון כמו Cosine Similarity לדירוג מסמכים.
  • מתחשב בגודל המסמך והשאילתה (בניגוד למודל הבוליאני).
  • אפשר לבצע שאילתות בטקסט חופשי, ללא צורך באופרטורים בוליאניים.
  • המטריצה N × D אמנם גדולה אך ספארסית — אפשר לנצל מימוש sparse לחיסכון בזיכרון.

❌ חסרונות / מגבלות

  • מפספס תוצאות שלא משתמשות במונח המדויק (אין הבנה של סינונימים).
  • אינו מתחשב בתדירות המילה בקורפוס כולו — מילים נפוצות מאוד (כמו 'the') מקבלות משקל גבוה מדי.
  • אינו מתחשב בסדר המילים במשפט.

🛠️ איך פותרים / מטפלים?

  • שקלול לפי נדירות (TF-IDF) — כדי שמילים נפוצות יקבלו משקל נמוך יותר.
  • הוספת n-grams (bigrams/trigrams) לתפיסת ביטויים רב-מילתיים.
  • מעבר לייצוגים סמנטיים (Word Embeddings) כדי לתפוס משמעות וסינונימים.

🔄 קשר לנושאים אחרים

BoW הוא הבסיס שעליו בנויות שיטות מתקדמות יותר: TF-IDF הוא שקלול של BoW; LDA לוקח מטריצת BoW (Document-Term Matrix) כקלט; ומודלי Embeddings מנסים לפתור את המגבלות הסמנטיות של BoW.

💻 קוד לדוגמה

from sklearn.feature_extraction.text import CountVectorizer
model = CountVectorizer()
matrix = model.fit_transform(docs)  # term-document count matrix

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין Binary Incidence Matrix לבין Bag-of-Words?

ת: ב-Incidence המטריצה בינארית (0/1), ואילו ב-BoW נשמרת ספירה מלאה של מספר המופעים של כל מילה.

ש: מה החיסרון המרכזי של BoW שדורש שקלול TF-IDF?

ת: BoW מתייחס לכל המילים הנפוצות (כמו 'the') באותו אופן כמילים נדירות ואינפורמטיביות — TF-IDF מתקן זאת.
