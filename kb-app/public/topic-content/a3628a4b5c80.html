📋 הגדרה

שיפורים על AdaGrad המחליפים את סכום ריבועי הגרדיאנטים המצטבר בממוצע נע אקספוננציאלי (Exponential Moving Average), כדי למנוע מה-learning rate האפקטיבי לדעוך לאפס באימונים ארוכים.

⚙️ איך זה עובד

  1. מאתחלים ממוצע נע של ריבועי גרדיאנטים E[g2]=0.
  2. בכל איטרציה מחשבים את הגרדיאנט g_t ומעדכנים את הממוצע הנע שלו.
  3. מחשבים learning rate אפקטיבי: α חלקי שורש הממוצע הנע (פלוס אפסילון).
  4. מעדכנים את הפרמטרים (ב-AdaDelta אף לא נדרש α כלל — הוא מוערך מהיחס בין עדכוני העבר לגרדיאנטים).

🎯 שימושים עיקריים

  • אימון רשתות עמוקות לא-קונבקסיות (RMSProp נפוץ מאוד ב-RNN/LSTM)

✅ יתרונות

  • פותר את בעיית ה-LR הדועך של AdaGrad
  • מתאים learning rate per-parameter בלי לדרוש כיוון ידני
  • AdaDelta אף לא דורש בחירת α כלל

❌ חסרונות / מגבלות

  • עדיין יש היפר-פרמטרים לכוון (ρ, ε)
  • פחות נפוץ כיום מ-Adam שמשלב גם Momentum

💻 קוד לדוגמה (Python / PyTorch)

import torch

model = torch.nn.Linear(10, 1)
optimizer = torch.optim.RMSprop(model.parameters(), lr=0.001, alpha=0.9)

for x_batch, y_batch in dataloader:
    optimizer.zero_grad()
    loss = torch.nn.functional.mse_loss(model(x_batch), y_batch)
    loss.backward()
    optimizer.step()

🧠 שאלות ראיון נפוצות

ש: איך RMSProp פותר את בעיית ה-LR הדועך של AdaGrad?

ת: במקום סכום מצטבר שגדל ללא הגבלה, RMSProp משתמש בממוצע נע אקספוננציאלי שמאפשר ל-LR האפקטיבי להתאושש אם הגרדיאנטים האחרונים קטנים.

ש: מה ההבדל המעשי בין RMSProp ל-AdaDelta?

ת: AdaDelta מרחיק לכת צעד נוסף ומבטל את הצורך בלבחור α כלל, על ידי הערכת גודל הצעד מתוך יחס עדכוני העבר לגרדיאנטים.
