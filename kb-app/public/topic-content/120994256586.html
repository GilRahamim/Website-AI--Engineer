📋 הגדרה

חיבור agent ב-CrewAI ל-retriever (מסד וקטורי) מאפשר לו לבסס (ground) את תשובותיו על מסמכים רלוונטיים אמיתיים — משלב את הגמישות המבנית של agent workflows עם עומק הידע של retrieval מבוסס-מסמכים.

🏛️ זרימת העבודה

User Query → Retriever (Vector DB) → Relevant Documents → CrewAI Agent → Grounded Response

🎯 יתרונות השילוב

  • תשובות מבוססות-עדות (grounded) ולא רק על ידע גנרי של ה-LLM.
  • מפחית hallucinations — ה-agent מצטט מקורות ([KB-#]) מתוך מסד הידע הפנימי.
  • מתאים הקשר בזמן אמת — מתעדכן עם המסמכים שבמסד, לא תלוי ב-knowledge cutoff.

💻 קוד לדוגמה — בניית/טעינת מסד וקטורי ו-Agent מחקר

def load_pdf_chunks(pdf_path: str):
pages = PyMuPDFLoader(pdf_path).load()
splitter = RecursiveCharacterTextSplitter(chunk_size=700, chunk_overlap=100)
chunks = splitter.split_documents(pages)
for i, c in enumerate(chunks):
c.metadata.setdefault(&quot;source&quot;, pdf_path)
c.metadata[&quot;chunk_id&quot;] = i
return chunks

🧠 שאלות ראיון נפוצות

ש: מה תפקיד max_iter בהגדרת Agent ב-RAG context?

ת: מגביל את מספר הצעדים/קריאות הכלים שה-agent מבצע באיטרציה בודדת — מונע לופים אינסופיים של חיפוש-חיפוש-חיפוש בלי להגיע לתשובה סופית.

ש: למה דרישת ציטוט [KB-#] חשובה ב-agent מבוסס-RAG?

ת: היא מאלצת את ה-agent להראות איזה chunk תומך בכל טענה — מאפשרת אימות (auditability) ועוזרת לזהות מקרים שבהם תשובה לא נתמכת בפועל בהקשר שנשלף.
