📋 הגדרה

כדי לבנות Knowledge Graph נדרשים טריפלטים (subject, relation, object). במקום regex ידני, מבקשים מ-LLM לקרוא כל מסמך ולהפיק טריפלטים בפורמט JSON — לאחר מכן בונים מהם גרף מכוון (directed multigraph) ומפעילים עליו אלגוריתמי אחזור.

⚙️ איך זה עובד

  • 1. שליחת כל מסמך ל-LLM עם system prompt שמורה לו לחלץ triples בפורמט JSON תקני.
  • 2. בניית גרף מכוון (NetworkX MultiDiGraph) — כל subject/object הוא node, כל triple הוא edge עם relation, doc_id ו-sentence תומך.
  • 3. אחזור גרפי (graph_retrieve) — איתור seed entities מתאימים לשאלה, הרחבת frontier מספר hops, אגירת קשתות נתמכות.
  • 4. אחזור מקביל ב-keyword (חפיפת token) ו-vector (embeddings) לצורך השוואה.
  • 5. בניית context סופי מהתוצאות הממוספרות ([1], [2]...) להזנה ל-LLM.

💻 קוד לדוגמה — אחזור גרפי מרובה-hops

def graph_retrieve(query: str, max_hops: int = 2, max_sentences: int = 8):
seeds = find_seed_entities(query)
visited = set(seeds)
frontier = set(seeds)
collected_edges = []
for _ in range(max_hops):
next_frontier = set()
for node in frontier:
for _, neighbor, data in G.out_edges(node, data=True):
collected_edges.append((node, neighbor, data))
if neighbor not in visited:
next_frontier.add(neighbor); visited.add(neighbor)
for neighbor, _, data in G.in_edges(node, data=True):
collected_edges.append((neighbor, node, data))
if neighbor not in visited:
next_frontier.add(neighbor); visited.add(neighbor)
frontier = next_frontier
return collected_edges

🎯 שימושים עיקריים

  • בניית KG אוטומטית ממסמכי טקסט לא-מבניים, ללא צורך בכללי regex ידניים.
  • בסיס לאחזור multi-hop ול-agents מבוססי-גרף.

✅ יתרונות

  • LLM מתמודד בקלות עם ניסוחים מגוונים של אותו יחס, בניגוד ל-regex שביר.
  • JSON מבני מאפשר ולידציה ובדיקת תקינות אוטומטית.

❌ חסרונות / מגבלות

  • דיוק חילוץ תלוי באיכות ה-LLM ובניסוח ה-prompt; שגיאות נספחות (cascading) לגרף.
  • דורש נורמליזציה של ישויות/יחסים (לדוגמה: "Tesla" מול "Tesla Inc.") כדי למנוע פיצול שגוי של nodes.

🧠 שאלות ראיון נפוצות

ש: מדוע להשתמש ב-LLM לחילוץ טריפלטים במקום regex?

ת: regex שביר לניסוחים מגוונים ודורש כללים ידניים לכל סוג יחס; LLM מבין הקשר סמנטי ומסוגל להפיק triples עקביים מניסוחים שונים של אותו מידע, עם JSON מבני שניתן לוולידציה.

ש: מה ההבדל בין graph_retrieve ל-vector_retrieve במימוש?

ת: graph_retrieve מתחיל מ-seed entities ומרחיב frontier על קשתות מוטיפסות (in/out edges) למספר hops; vector_retrieve מחשב cosine similarity בין embedding השאלה לבין embeddings של כל הקורפוס ומחזיר top-k.
