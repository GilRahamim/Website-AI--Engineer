📋 הגדרה

אימון מודל YOLO מותאם-אישית על דאטה ייעודי, באמצעות Transfer Learning — המשך אימון ממשקלים pretrained (לא מאפס) לזיהוי קטגוריות חדשות שלא היו בדאטהסט המקורי (כגון COCO).

⚙️ צנרת האימון (Training Pipeline)

  • 1. Dataset — אוסף תמונות עם תיוג.
  • 2. Labels — קואורדינטות bounding box + class לכל אובייקט.
  • 3. Transfer Learning — התחלה ממשקלים pretrained.
  • 4. Training — אימון על הדאטה הספציפי.
  • 5. Validation — הערכה על סט אימות.
  • 6. Best Weights — שמירת המשקלים הטובים ביותר.
  • 7. Inference — שימוש במודל המאומן על תמונות חדשות.

🔑 מדוע Transfer Learning קריטי

לא מאמנים מאפס (NOT training from scratch). במקום זאת: מתחילים ממשקלים pretrained, משתמשים מחדש בתכונות חזותיות שכבר נלמדו (reuse learned visual features), ו-fine-tune על הדאטה הספציפי. יתרונות: אימון מהיר יותר, פחות דאטה נדרש, ביצועים טובים יותר — בדיוק כעקרון ה-Fine-Tuning שנדון במסמכים 51-54, כאן מיושם על מודלי vision.

💻 קוד לדוגמה — הגדרת דאטהסט ואימון

COCO128 (128 תמונות, 80 קטגוריות) הוא דוגמית קטנה שמורידה אוטומטית ע&quot;י Ultralytics. לדאטה אישי, מצביעים על קובץ YAML:
# data.yaml
path: ../datasets/my_data
train: images/train
val: images/val
names:
0: cat

# 10_train_yolo.py

💻 קוד לדוגמה — חיזוי עם מודל מאומן

זרימה: Train → Save Weights → Load Model → Predict on New Images.

✅ יתרונות Transfer Learning

  • אימון מהיר משמעותית מאימון from-scratch.
  • דורש פחות דאטה מתויג — קריטי כשתיוג ידני יקר.
  • מבצע טוב יותר בדרך כלל ממודל שאומן מאפס על דאטה קטן.

🧠 שאלות ראיון נפוצות

ש: מדוע COCO128 משמש כדוגמית הדגמה ולא COCO המלא (כ-330,000 תמונות)?

ת: כי המטרה בדמו היא להדגים את ה-pipeline (data → labels → transfer learning → training → validation → inference) בזמן קצר ועל משאבים מוגבלים — COCO128 (128 תמונות) מספיק להראות שהקוד עובד מקצה לקצה, בלי לדרוש שעות אימון על דאטהסט מלא.

ש: מה ההבדל בין 'transfer learning' ב-YOLO ל'fine-tuning embeddings' שנדון במסמך 51?

ת: שניהם מבוססים על אותו עיקרון — להמשיך אימון ממשקלים pretrained במקום מאפס — אך התחום שונה: YOLO transfer learning מתאים שכבות חזותיות (visual features, קצוות/טקסטורות/צורות) למשימת detection חדשה; embedding fine-tuning מתאים את מרחב הדמיון הטקסטואלי למשימת retrieval. העקרון המתמטי-מושגי דומה, התחום (vision מול NLP) שונה.
