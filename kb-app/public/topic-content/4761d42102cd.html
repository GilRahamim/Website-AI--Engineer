הגדרה

ספריית הגרפים הוותיקה של Python והבסיס שעליו בנויות Seaborn ו-pandas.plot. היא מציעה שליטה מלאה בכל אלמנט בגרף, במחיר של קוד ארוך יותר מאשר בעטיפות ברמה גבוהה.

שתי דרכי עבודה

גישהאיך נראיתמתי מתאימה
Functional (pyplot)plt.plot(x, y) · plt.title(...)גרף מהיר אחד בזמן חקירה
Object-Orientedfig, ax = plt.subplots() · ax.plot(x, y)כל השאר — במיוחד כמה תתי-גרפים

הגישה המומלצת היא Object-Oriented: מחזיקים במפורש את אובייקט ה-Figure (הקנבס) ואת אובייקטי ה-Axes (הגרפים עליו), ולכן ברור בכל שורה על מה בדיוק פועלים. בגישה הפונקציונלית פועלים על ``הגרף הנוכחי'' — נוח לגרף אחד, מבלבל כשיש כמה.

המבנה הבסיסי

import matplotlib.pyplot as plt
%matplotlib inline          # ב-Jupyter; מחוץ לו צריך plt.show()

# גישה פונקציונלית — לגרף מהיר
plt.plot(x, y, 'r--')
plt.xlabel('X'); plt.ylabel('Y'); plt.title('Title')

# גישה מונחית-עצמים — מומלצת
fig, ax = plt.subplots(figsize=(8, 4), dpi=100)
ax.plot(x, y, color='#2E75B6', lw=2, ls='-', marker='o', markersize=6,
        label='series 1')
ax.set_xlabel('X'); ax.set_ylabel('Y'); ax.set_title('Title')
ax.set_xlim([0, 10]); ax.set_ylim([0, 100])
ax.legend(loc=0)            # 0 = מיקום אוטומטי
fig.tight_layout()          # מונע חפיפה בין תוויות
fig.savefig('plot.png', dpi=200, bbox_inches='tight')

כמה גרפים על אותו קנבס

fig, axes = plt.subplots(nrows=1, ncols=2, figsize=(12, 4))

axes[0].plot(x, y);      axes[0].set_title('First')
axes[1].scatter(x, y);   axes[1].set_title('Second')

# רשת דו-ממדית: axes הוא מערך דו-ממדי
fig, axes = plt.subplots(2, 2)
axes[1, 0].hist(data, bins=30)

plt.tight_layout()

plt.subplots מחזיר זוג: ה-Figure ומערך של Axes. אם ביקשו יותר מגרף אחד, axes הוא מערך NumPy — במקרה של רשת הוא דו-ממדי ומאונדקס [שורה, עמודה].

סוגי גרפים נפוצים

  • plt.plot — קו; לסדרות מסודרות ולסדרות עת.
  • plt.scatter — פיזור; לקשר בין שני משתנים רציפים.
  • plt.hist(data, bins=30) — היסטוגרמה; להתפלגות משתנה אחד.
  • plt.boxplot — קופסה; לחציון, רבעונים וחריגים.
  • plt.imshow — מטריצה כתמונה; לתמונות ולמפות חום פשוטות.

שאלות ראיון נפוצות

ש: מה ההבדל בין Figure ל-Axes?

ת: Figure הוא הקנבס כולו — החלון או הקובץ. Axes הוא גרף בודד עליו, עם צירים, תוויות ונתונים משלו. קנבס אחד יכול להכיל כמה Axes; לכן ax.set_title קובע כותרת לתת-גרף בעוד fig.suptitle קובע כותרת-על לכל הקנבס.

ש: למה עדיף את הגישה המונחית-עצמים?

ת: כי היא מפורשת: כל פקודה מופנית לאובייקט מסוים. בגישה הפונקציונלית כל פקודה פועלת על ``הגרף הפעיל'', ומרגע שיש יותר מגרף אחד קשה לעקוב מי פעיל ברגע נתון.

ש: מה tight_layout פותר?

ת: חפיפה בין תוויות צירים, כותרות ותתי-גרפים. Matplotlib אינו מחשב מראש כמה מקום התוויות צריכות; tight_layout מודד אותן אחרי הציור ומתאים את הרווחים.
