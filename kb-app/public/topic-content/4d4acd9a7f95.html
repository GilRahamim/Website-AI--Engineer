📋 הגדרה

ארכיטקטורת רשת עצבית המתמחה בעיבוד נתונים בעלי מבנה מרחבי (תמונות בעיקר), המבוססת על שכבות קונבולוציה המשתפות משקולות (Filters) על פני כל המרחב הקלט.

🏛️ מבנה הרשת

  • שכבות קונבולוציה (Convolutional Layers) — מריצות פילטרים קטנים על פני התמונה לחילוץ פיצ'רים מקומיים
  • שכבות Pooling (בד"כ Max Pooling) — מקטינות את הרזולוציה המרחבית ומוסיפות שונות (Invariance) להזזות קטנות
  • שכבות Fully-Connected בסוף הרשת — ממירות את מפות הפיצ'רים לתחזית סופית (סיווג / רגרסיה)

📐 נוסחאות מפתח

🎯 תחומי שימוש

  • סיווג תמונות (Image Classification)
  • גילוי אובייקטים (Object Detection) ופילוח תמונה (Segmentation)
  • עיבוד אותות חד-מימדיים (אודיו, סיגנלים זמניים) באמצעות Conv1D

✅ יתרונות

  • שיתוף משקולות (Weight Sharing) מקטין דרמטית את מספר הפרמטרים לעומת MLP
  • Translation Invariance — מזהה דפוס בלי קשר למיקומו בתמונה
  • לומד היררכיה של פיצ'רים: קצוות → טקסטורות → חלקים → אובייקטים שלמים

❌ מגבלות

  • דורש כמות גדולה של דאטה מתויג לאימון מאפס
  • פחות מתאים מטבעו לרצפים ארוכים או נתונים לא-רשתיים (Non-Grid)
  • שדה הקליטה (Receptive Field) מוגבל ללא רשתות עמוקות מאוד או Dilated Convolutions

💻 קוד לדוגמה (PyTorch)

import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=3, padding=1), nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Linear(64 * 8 * 8, 10)

    def forward(self, x):
        x = self.features(x)
        x = x.flatten(1)
        return self.classifier(x)

🧠 שאלות ראיון נפוצות

ש: מה היתרון של Weight Sharing בקונבולוציה?

ת: אותו פילטר מופעל על כל אזורי התמונה, כך שמספר הפרמטרים לא תלוי בגודל התמונה, וניתן ללמוד אותו דפוס בכל מיקום.

ש: מה תפקיד שכבות ה-Pooling?

ת: מקטינות את הרזולוציה המרחבית (Downsampling), מפחיתות עומס חישובי ומוסיפות חוסר-רגישות קטן להזזות ולעיוותים קלים.
