📋 הגדרה

שיטה לפירוק מטריצה גדולה (לדוגמה מטריצת משתמש-פריט בהמלצות) לשתי מטריצות קטנות יותר בעלות מימד סמוי (latent dimension) משותף, כך שמכפלתן משחזרת בקירוב את המטריצה המקורית.

⚙️ איך זה עובד

  1. מתחילים ממטריצה R בגודל m x n (לדוגמה: משתמשים x פריטים) עם ערכים חלקיים בלבד (דירוגים ידועים).
  2. מאתחלים שתי מטריצות סמויות: U בגודל m x k ו-V בגודל n x k (k הוא מימד סמוי קטן).
  3. מחשבים את החיזוי לכל זוג (משתמש, פריט) כמכפלה פנימית של השורות המתאימות ב-U וב-V.
  4. מחשבים Loss (לדוגמה MSE) רק על הערכים הידועים, ומעדכנים את U ו-V בעזרת gradient descent.
  5. חוזרים על העדכון עד להתכנסות; ניתן להוסיף איבר רגולריזציה למניעת Overfitting.

📐 נוסחאות

שחזור:

פונקציית מטרה עם רגולריזציה:

🎯 שימושים עיקריים

  • מערכות המלצה (Recommender Systems) — חיזוי דירוג משתמש לפריט שלא נצפה
  • הקטנת מימד (dimensionality reduction) של דאטה דליל
  • Embedding של ישויות (משתמשים, פריטים, מילים) למרחב וקטורי סמוי

✅ יתרונות

  • יעיל לדאטה דליל מאוד (כגון מטריצות דירוג עם רוב הערכים חסרים)
  • חולץ ייצוגים סמויים (latent factors) שמלמדים על העדפות/תכונות נסתרות
  • ניתן להרחבה עם רגולריזציה, bias terms, ושיטות הסתברותיות (Probabilistic MF)

❌ חסרונות / מגבלות

  • מתקשה עם ה-Cold Start Problem — משתמשים/פריטים חדשים בלי היסטוריה
  • מניח קשר לינארי (מכפלה פנימית) בין U ו-V, מה שמגביל את הביטוי של דפוסים מורכבים
  • לא תמיד תופס הקשר זמני (temporal dynamics) בהעדפות

💻 קוד לדוגמה (Python / PyTorch)

import torch
import torch.nn as nn

class MatrixFactorization(nn.Module):
    def __init__(self, n_users, n_items, k=20):
        super().__init__()
        self.U = nn.Embedding(n_users, k)
        self.V = nn.Embedding(n_items, k)

    def forward(self, user_ids, item_ids):
        return (self.U(user_ids) * self.V(item_ids)).sum(dim=1)  # מכפלה פנימית

🧠 שאלות ראיון נפוצות

ש: מה ה-Cold Start Problem וכיצד הוא קשור ל-Matrix Factorization?

ת: זו הבעיה של חיזוי דירוג למשתמש או פריט חדש שאין לו היסטוריית דירוגים — מאחר ש-MF לומד את הווקטורים הסמויים מתוך דירוגים ידועים בלבד, אין לו מידע ללמוד ממנו עבור ישויות חדשות.

ש: מה הקשר בין Matrix Factorization ל-Embedding Layer?

ת: שניהם מייצרים ייצוג וקטורי סמוי (latent vector) לישות בדידה; Matrix Factorization הוא בעצם מקרה פרטי שבו שתי טבלאות Embedding (משתמשים ופריטים) מאומנות יחד כך שהמכפלה הפנימית שלהן משחזרת מטריצת אינטראקציות.
