📋 הגדרה

FastMCP הוא תבנית מימוש (framework קל-משקל) לבניית שרתי MCP באמצעות FastAPI. הוא משתמש ב-FastAPI כשכבת transport ו-orchestration ל-agents/כלי MCP, במקום לכתוב לוגיקת שרת MCP גולמית, וחושף כלים, agents ו-pipelines מעל MCP במאמץ מינימלי.

🏛️ רעיונות מפתח

  • Tools as FastAPI Endpoints — כל כלי MCP הוא endpoint (לדוגמה: POST /tools/medline_lookup), ונרשם באמצעות דקורטור @tool כתואם-MCP.
  • Agents as Orchestrators — agent מוגדר (לדוגמה: medication summarizer) שקורא לאותם כלים ומתאם זרימות מרובות-שלבים (fetch → parse → upsert).
  • Pipelines as Workflows — קיבוץ agents+כלים לזרימות (כגון patient medication enrichment), מורצות דרך שרת MCP עם jobs/tasks.
  • MCP Server = FastAPI App — אפליקציית FastAPI רגילה, אך חושפת schema של MCP, רישום כלים ותיאום agents; ניתן להריץ via uvicorn או בתוך Docker.

💻 קוד לדוגמה — הגדרת כלי MCP

mcp = FastMCP()
NWS_API_BASE = &quot;https://api.weather.gov/&quot;
@mcp.tool()
async def get_alerts(state: str) -&gt; str:
&quot;&quot;&quot;Return raw active weather alerts for a two-letter US state.&quot;&quot;&quot;
url = f&quot;{NWS_API_BASE}alerts/active?area={state}&quot;
data = await make_nws_request(url)
if not data or &quot;features&quot; not in data or not data[&quot;features&quot;]:
return f&quot;No active alerts found for {state}.&quot;
out = []
for feat in data[&quot;features&quot;]:
props = feat.get(&quot;properties&quot;, {})
out.append(
f&quot;Event: {props.get('event','?')}\n&quot;
f&quot;Area: {props.get('areaDesc','?')}\n&quot;
f&quot;Severity: {props.get('severity','?')}&quot;)
return &quot;\n---\n&quot;.join(out)
@mcp.tool()
async def explain_alert(feature: Dict[str, Any]) -&gt; str:
&quot;&quot;&quot;Ask GPT to explain one alert feature in plain English.&quot;&quot;&quot;
props = feature.get(&quot;properties&quot;, {})
prompt = (f&quot;Here's a weather alert:\nEvent: {props.get('event')}\n&quot;
f&quot;Severity: {props.get('severity')}\nExplain what this means.&quot;)
resp = client.chat.completions.create(
model=&quot;gpt-4o-mini&quot;, messages=[{&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: prompt}])
return resp.choices[0].message.content

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין FastMCP ל-MCP הגולמי?

ת: FastMCP הוא שכבת נוחות מעל FastAPI שמאפשרת לחשוף כלי MCP כ-endpoints רגילים עם דקורטור @tool, בלי לכתוב את לוגיקת פרוטוקול ה-MCP הגולמית מאפס — מקצר משמעותית את ה-boilerplate.

ש: מהי דוגמה ל-pipeline שמשתמש בכלי MCP מרובים?

ת: fetch → parse → upsert: כלי MCP אחד מביא מידע, agent מפענח/מנתח אותו, וכלי נוסף שומר את התוצאה — כל שלב הוא endpoint MCP נפרד שמתואם בתוך אותו pipeline.
