📋 הגדרה

LoRA (Low-Rank Adaptation) היא שיטת PEFT (Parameter-Efficient Fine-Tuning) המאמנת adapter קטן ('Low-Rank') במקום את כל משקלי המודל. QLoRA משלבת זאת עם quantization ל-4-bit של המודל הבסיסי — כך שניתן לאמן adapters על GPU בודד או laptop, בעוד המודל הבסיסי (frozen) נשאר מקוונטז וקפוא.

⚙️ איך זה עובד

  • 1. טעינת tokenizer + מודל בסיס בקוונטיזציית 4-bit (BitsAndBytesConfig, nf4).
  • 2. הכנת המודל לאימון k-bit (prepare_model_for_kbit_training).
  • 3. הגדרת LoraConfig — דרגת ה-adapter (r), lora_alpha, dropout, ויעדי השכבות (target_modules כגון q_proj/k_proj/v_proj/o_proj).
  • 4. Tokenization של הדאטה (טקסט חופשי, או chat-formatted עם apply_chat_template).
  • 5. אימון עם Trainer רגיל — רק משקלי ה-adapter מתעדכנים; המודל הבסיסי קפוא.
  • 6. שמירת ה-adapter בנפרד, וטעינתו מעל המודל הבסיסי בזמן inference (PeftModel.from_pretrained).

📐 עקרון מתמטי

המשקל המקורי W0 נשאר קפוא; מתאמנת רק תוספת מדרגה נמוכה (low-rank) ΔW = BA, שמספר הפרמטרים בה קטן בהרבה ממספר הפרמטרים המלא של השכבה.

🔄 טקסט חופשי לעומת Chat Roles

גישהמאפיינים
טקסט חופשי (raw continuation)אין system prompt / chat template; המודל לומד להמשיך טקסט בסטייל נתון (לדוגמה rap lyrics) ישירות
Chat Roles + Prompt Engineeringדאטה מאורגן כ-{prompt, completion} / messages עם roles (system/user/assistant); משתמשים ב-apply_chat_template; מתאים לשימוש production עם system prompt עקבי

✅ יתרונות

  • ניתן לאמן על GPU בודד או laptop — בזכות quantization ל-4-bit.
  • המודל הבסיסי קפוא — אפשר להחזיק כמה adapters קלים (לתחומים/סטיילים שונים) מעל אותו base.
  • פחות prompt engineering נדרש בזמן inference — ההתנהגות 'מקודדת' ב-adapter.

❌ חסרונות / מגבלות

  • לא מוסיף ידע עובדתי חדש — רק משנה style/tone/structure/consistency.
  • עדיין תלוי ב-retrieval טוב אם המשימה דורשת מידע עדכני (RAG עדיין נחוץ).
  • rank r נמוך מדי עלול להגביל את יכולת ההסתגלות; rank גבוה מדי מתקרב לעלות full fine-tuning.

🧠 שאלות ראיון נפוצות

ש: מדוע QLoRA מאפשרת אימון על GPU יחיד כשהמודל המקורי לא היה נכנס לזיכרון ב-fp16?

ת: כי המודל הבסיסי נטען בקוונטיזציית 4-bit (nf4) ונשאר קפוא — רק משקלי ה-adapter (B,A, מדרגה נמוכה r) מתעדכנים ונשמרים ב-fp16/fp32, כך שטביעת הזיכרון של gradients ו-optimizer states קטנה בהרבה מאימון מלא.

ש: מה ההבדל בין אימון על טקסט חופשי לאימון עם chat template?

ת: טקסט חופשי מאמן את המודל להמשיך טקסט גולמי (ללא system prompt) — דורש שהפרומפט בזמן inference יהיה בפורמט תואם. אימון עם chat template (apply_chat_template) מלמד את המודל להגיב לפי roles מובנים (system/user/assistant) — תואם לשימוש production סטנדרטי.
