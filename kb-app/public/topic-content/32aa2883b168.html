📋 הגדרה

גרסה מתקדמת של RNN המוסיפה מנגנון שערים (Gates) ו-Cell State נפרד, המאפשרים לרשת לזכור מידע לאורך רצפים ארוכים בלי לסבול מ-Vanishing Gradients באותה חדות.

🏛️ מבנה הרשת

  • Forget Gate — קובע אילו פרטים מה-Cell State הקודם לשכוח
  • Input Gate — קובע אילו פרטים חדשים להוסיף ל-Cell State
  • Cell State $C_t$ — "זיכרון" ארוך-טווח שעובר בין צעדי הזמן עם מעט שינוי
  • Output Gate — קובע מה מתוך ה-Cell State ייחשף כ-Hidden State הנוכחי

🎯 תחומי שימוש

  • תרגום מכונה ומודלים שפתיים לפני עידן ה-Transformer
  • חיזוי סדרות זמן ארוכות (פיננסים, חיישנים)
  • זיהוי דיבור (Speech Recognition)

✅ יתרונות

  • מתמודדת טוב בהרבה מ-Vanilla RNN עם תלויות ארוכות טווח
  • מנגנון השערים מאפשר שליטה מפורשת על זרימת המידע
  • עדיין רלוונטית למשימות רצפיות עם משאבים מוגבלים

❌ מגבלות

  • מורכבת חישובית יותר מ-RNN רגילה (יותר פרמטרים)
  • עדיין סדרתית באופייה — איטית יותר מ-Transformer בזמן אימון
  • הוחלפה ברוב משימות ה-NLP המודרניות על ידי ארכיטקטורות מבוססות Attention

💻 קוד לדוגמה (PyTorch)

import torch.nn as nn

lstm = nn.LSTM(input_size=128, hidden_size=256, num_layers=1, batch_first=True)
output, (h_n, c_n) = lstm(x)  # x: (batch, seq_len, input_size)

🧠 שאלות ראיון נפוצות

ש: מה ההבדל המרכזי בין LSTM ל-RNN רגילה?

ת: LSTM מוסיפה Cell State נפרד ומנגנון שערים (Forget/Input/Output) שמאפשרים לרשת לשמור או למחוק מידע באופן מבוקר, ובכך להתמודד טוב יותר עם תלויות ארוכות טווח.

ש: מה ההבדל בין LSTM ל-GRU?

ת: GRU מאחדת את Forget ו-Input Gate לשער עדכון יחיד ומבטלת את ה-Cell State הנפרד — פחות פרמטרים ומהירה יותר, אך לעיתים פחות מבטאת ביצועים מ-LSTM במשימות מורכבות.
