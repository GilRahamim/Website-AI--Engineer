📋 הגדרה

מדד דמיון בין שתי קבוצות (לדוגמה — קבוצות המילים הייחודיות בשני מסמכים), המוגדר כגודל החיתוך שלהן חלקי גודל האיחוד שלהן.

📐 הנוסחה

דמיון ז'קארד בין קבוצות A ו-B

מרחק ז'קארד — המשלים לדמיון

🔡 פירוש משתנים

משתנהמשמעות
A, Bשתי הקבוצות (לדוגמה: קבוצות המילים בשני מסמכים)
החיתוך — איברים המשותפים לשתי הקבוצות
האיחוד — כל האיברים בשתי הקבוצות יחד

📊 תכונות חשובות

  • תחום הערכים: 0 ≤ J(A,B) ≤ 1 — כאשר 1 פירושו קבוצות זהות, 0 פירושו קבוצות זרות לחלוטין (ללא חפיפה).
  • המדד מתייחס לקבוצות (set-based) ולא לתדירות — שני מסמכים עם מילה משותפת אחת שמופיעה פעם אחת או מאה פעמים נחשבים זהים מבחינת ז'קארד.
  • סימטרי: J(A,B) = J(B,A).

🎯 מתי משתמשים?

  • השוואת קבוצות מילים/n-grams של שני מסמכים, ללא תלות בתדירות.
  • זיהוי כפילויות (deduplication) ו-Record Linkage כאשר משווים סטים של תווים/אסימונים.
  • מדידת דמיון בין סטים בכלל — לא רק בטקסט (לדוגמה: רשימות מוצרים, תגיות).

🔄 השוואה לפונקציות דומות

פונקציהמתי עדיפה

💻 מימוש בקוד

def jaccard_similarity(set_a, set_b):
intersection = len(set_a &amp; set_b)
union = len(set_a | set_b)
return intersection / union if union else 0.0
jaccard_similarity({'cat','dog','bird'}, {'dog','bird','fish'})  # 2/4 = 0.5

🧠 שאלות ראיון נפוצות

ש: מה ההבדל המהותי בין דמיון ז'קארד לדמיון קוסינוס?

ת: ז'קארד מתבסס על קבוצות (נוכחות/היעדרות בלבד), בעוד קוסינוס מתבסס על וקטורים משוקללים ולוקח בחשבון תדירות/עוצמה.

ש: מה יקרה לדמיון ז'קארד אם שתי הקבוצות זרות לחלוטין?

ת: החיתוך יהיה ריק (0), ולכן הדמיון יהיה 0 — המינימום האפשרי.
