📋 הגדרה

Hybrid Search משלב חיפוש מילות-מפתח (BM25) עם חיפוש סמנטי וקטורי, כדי לכסות גם התאמות מדויקות (מזהים, שמות תרופות, קודי שגיאה) וגם ניסוחים שונים באותה משמעות (paraphrases), ולשפר recall מבלי לפגוע ב-precision.

⚙️ איך זה עובד (Late Fusion)

  1. שליפת top-N מועמדים באמצעות BM25 (מבוסס מילות מפתח).
  2. שליפת top-M מועמדים באמצעות חיפוש וקטורי (embedding similarity).
  3. מיזוג (merge) והסרת כפילויות (deduplication) בין שתי הרשימות.
  4. Re-ranking של הקבוצה המאוחדת (Cross-Encoder או MMR) ובחירת top-k סופי.

📐 נוסחאות — אופציות לאיחוד ציונים

מיזוג משוקלל (Weighted blend), עם α=0.5 כברירת מחדל:

Reciprocal Rank Fusion (RRF) — שיטה עמידה יותר בין סקאלות שונות:

כאשר ranki(d) הוא הדירוג של המסמך d ברשימה ה-i-ית (BM25 או סמנטית), ו-k הוא קבוע (לרוב k=60).

🎯 מתי להשתמש

  • שאילתות אמביגואליות, אוצר מילים מעורב, מסמכים ארוכים.
  • תחומים בעלי דרישת recall גבוהה (רפואה, משפט, compliance).
  • קורפוסים הטרוגניים (דוחות + FAQ + פניות תמיכה).

✅ יתרונות

  • מכסה גם התאמה מדויקת (BM25) וגם הבנה סמנטית (vectors) — recall גבוה יותר מכל שיטה בנפרד.
  • RRF עמיד לסקאלות ציונים שונות, ולא דורש כיול ידני מורכב.

❌ חסרונות / מגבלות ומלכודות

  • ממוצע של ציונים גולמיים בסקאלות שונות (BM25 מול cosine) ללא נורמליזציה נותן תוצאה שגויה.
  • ללא deduplication, כפילויות 'תופסות מקום' ומפחיתות גיוון בתוצאות.
  • אם N,M (גודל ה-retrieval הראשוני) קטנים מדי, re-ranking על קבוצה חסרה לא יעזור.

💻 קוד לדוגמה

from rank_bm25 import BM25Okapi
from sentence_transformers import SentenceTransformer, util
import numpy as np
tokenized_docs = [doc.split() for doc in documents]
bm25 = BM25Okapi(tokenized_docs)
model = SentenceTransformer('all-MiniLM-L6-v2')
doc_embeddings = model.encode(documents, convert_to_tensor=True)
query = &quot;treatment for Crohn's&quot;
bm25_scores = bm25.get_scores(query.split())
query_embedding = model.encode(query, convert_to_tensor=True)
cosine_scores = util.cos_sim(query_embedding, doc_embeddings)[0].cpu().numpy()
hybrid_scores = (bm25_scores + cosine_scores) / 2   # normalize first in practice
top_idx = np.argsort(hybrid_scores)[::-1][:3]

🧠 שאלות ראיון נפוצות

ש: מה היתרון של RRF על פני מיזוג משוקלל פשוט?

ת: RRF מתבסס על דירוג (rank) ולא על הציון הגולמי, ולכן הוא עמיד בפני הבדלי סקאלה בין BM25 לקוסינוס — אין צורך בנורמליזציה עדינה.

ש: מתי Hybrid Search קריטי במיוחד?

ת: כשהשאילתות כוללות גם מונחים מדויקים (מזהים, שמות) וגם צורך בהבנה סמנטית — למשל 'מספר תיק FHIR 12345' לצד 'איך מאתרים מידע מטופל מ-FHIR'.
