📋 הגדרה

Neo4j הוא מסד נתונים גרפי (graph database) שנועד לאחסון ולשאילתת קשרים. דאטה מיוצג כ-Nodes (ישויות, לדוגמה Tesla, BMW, CATL), Relationships (קשרים, לדוגמה SUPPLIES, USES) ו-Properties (תכונות, לדוגמה type, year, category). מותאם לשאילתות קשרים, traversal מרובה-hops וחקירת גרף.

💻 קוד לדוגמה — שאילתת Cypher בסיסית

MATCH (s)-[:SUPPLIES]-&gt;(t:Company {name: &quot;Tesla&quot;})
RETURN s

💻 קוד לדוגמה — הרצת Neo4j ב-Docker וחיבור מ-Python

# .env
NEO4J_URI=bolt://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=testpassword
# Run Neo4j (Docker)
docker run -d --name neo4j-demo \
-p 7474:7474 -p 7687:7687 \
--env-file neo4j.env \
-e NEO4JLABS_PLUGINS='[&quot;apoc&quot;]' \
-e NEO4J_dbms_security_procedures_unrestricted=apoc.* \
neo4j:5
graph = Neo4jGraph(
url=os.getenv(&quot;NEO4J_URI&quot;),
username=os.getenv(&quot;NEO4J_USERNAME&quot;),
password=os.getenv(&quot;NEO4J_PASSWORD&quot;),
)
graph.query(&quot;&quot;&quot;
MERGE (s:Entity {name: $subject})
MERGE (o:Entity {name: $object})
WITH s, o
CALL apoc.merge.relationship(s, $relation, {}, {doc_id: $doc_id, sentence: $sentence}, o, {})
YIELD rel
RETURN rel
&quot;&quot;&quot;, params={...})

💻 קוד לדוגמה — Text-to-Cypher עם GraphCypherQAChain

cypher_chain = GraphCypherQAChain.from_llm(
llm=ChatOpenAI(model=&quot;gpt-4o-mini&quot;, temperature=0),
graph=graph,
cypher_prompt=CYPHER_PROMPT,
qa_prompt=QA_PROMPT,
verbose=True,
allow_dangerous_requests=True,
)
response = cypher_chain.invoke({&quot;query&quot;: &quot;Which manufacturers source battery cells from CATL?&quot;})
print(&quot;Final answer:&quot;, response[&quot;result&quot;])
# Generated Cypher:
# MATCH (:Entity {name: 'CATL'})-[:supplies]-&gt;(m:Entity) RETURN m.name AS manufacturer
# UNION MATCH (m:Entity)-[:sources_from]-&gt;(:Entity {name: 'CATL'}) RETURN m.name AS manufacturer
# Final answer: BMW, Tesla, and Volkswagen source battery cells from CATL.

🎯 שימושים עיקריים

  • שאילתות יחסים (relationship queries) מורכבות בין ישויות מקושרות.
  • Traversal מרובה-hops לאיתור מסלולים בין ישויות מרוחקות בגרף.
  • חקירת גרף (graph exploration) פתוחה — "מה מחובר ל-X?"

🧠 שאלות ראיון נפוצות

ש: מה ה-APOC plugin מוסיף ל-Neo4j?

ת: פונקציות עזר (utility functions), פעולות גרפיות מתקדמות (כגון apoc.merge.relationship), ויכולות שאילתה דינמיות שאינן חלק מ-Cypher הבסיסי.

ש: מה היתרון של GraphCypherQAChain על פני כתיבת Cypher ידנית?

ת: מאפשר למשתמש לשאול בשפה טבעית, וה-LLM מתרגם אוטומטית לשאילתת Cypher (text-to-Cypher) על בסיס schema הגרף, מריץ אותה, ומחזיר תשובה בשפה טבעית — ללא צורך לדעת Cypher.
