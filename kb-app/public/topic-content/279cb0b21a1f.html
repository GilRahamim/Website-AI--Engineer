📋 הגדרה

סדרת שלבי עיבוד שמטרתם להמיר טקסט גולמי וחופשי (raw text) לצורה נקייה ואחידה, המתאימה להזנה לאלגוריתמי NLP — בין אם מודל קלאסי מבוסס BoW/TF-IDF ובין אם מודל מבוסס embeddings.

🔍 מתי זה קורה?

  • תמיד נדרש כשלב ראשון בכל צנרת NLP, לפני בניית ייצוג וקטורי (BoW, TF-IDF) או אימון מודל embeddings.
  • קריטי במיוחד כשמקור הטקסט 'מלוכלך' — רשתות חברתיות, סקרים פתוחים, OCR, תמלולים.

⚙️ שלבים נפוצים

  • Tokenization — פירוק הטקסט לטוקנים (מילים / תת-מילים / תווים).
  • Lowercasing — הפיכת כל הטקסט לאותיות קטנות, כדי ש-"Dog" ו-"dog" יחשבו לאותו טוקן.
  • הסרת סימני פיסוק (Punctuation Removal) ותווים מיוחדים שאינם תורמים משמעות.
  • הסרת מילות עצירה (Stopword Removal) — מילים נפוצות מאוד וחסרות תוכן ("the", "is", "של", "את") שלעיתים מוסרות בהתאם למשימה.
  • נרמול מורפולוגי: Stemming (קיצוץ גס של סיומות, מהיר אך פחות מדויק) או Lemmatization (החזרה לצורת המקור הדקדוקית, מדויק יותר אך יקר חישובית).
  • טיפול במספרים, אמוג'ים, קישורים (URLs) ותגי HTML — לרוב מוחזרים לפי הצורך הספציפי של המשימה.

⚠️ איך מזהים בעיה בעיבוד מקדים?

  • אוצר מילים (vocabulary) גדול ומתפוצץ באופן בלתי סביר — סימן שייתכן שצריך נרמול מורפולוגי טוב יותר.
  • מודל מתקשה למצוא דמיון בין מסמכים דומים מבחינה תוכנית אך כתובים בסגנון שונה.
  • המודל הסופי מתבסס יותר מהצפוי על מילים שכיחות-אך-לא-אינפורמטיביות.

🛠️ איך פותרים / מטפלים?

  • בדיקה שיטתית של אוצר המילים שמתקבל לאחר עיבוד — האם יש כפילויות מורפולוגיות שלא טופלו?
  • התאמת רשימת מילות העצירה למשימה הספציפית (לדוגמה — אין להסיר 'not' במשימת ניתוח סנטימנט).
  • שילוב n-grams / phrase detection לפני הייצוג הווקטורי, כדי לשמור ביטויים רב-מילתיים חשובים (לדוגמה "New York").

🔄 קשר לנושאים אחרים

העיבוד המקדים הוא תנאי הכרחי לפני בניית ייצוגי Bag-of-Words, TF-IDF, ואימון LDA. גם ב-N-grams & Phrase Detection מתבססים על אותו טוקניזציה בסיסית. לעומת זאת, מודלי הקשר עמוקים (Word2Vec/FastText) רגישים פחות לחלק מהשלבים (כמו הסרת מילות עצירה), אך עדיין דורשים טוקניזציה עקבית.

💻 קוד לדוגמה

import re
from nltk.corpus import stopwords
from nltk.stem import WordNetLemmatizer
def preprocess(text):
text = text.lower()
text = re.sub(r'[^a-z0-9\s]', '', text)
tokens = text.split()
tokens = [t for t in tokens if t not in stopwords.words('english')]
lemmatizer = WordNetLemmatizer()
return [lemmatizer.lemmatize(t) for t in tokens]

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין Stemming ל-Lemmatization?

ת: Stemming מקצץ סיומות באופן מכני/היוריסטי (מהיר אך עלול להפיק צורות לא תקינות), בעוד Lemmatization מחזיר את המילה לצורת המקור הדקדוקית הנכונה (precise יותר, אך יקר חישובית ודורש מילון/מודל שפה).

ש: מתי כדאי להימנע מהסרת מילות עצירה?

ת: במשימות שבהן מילות עצירה נושאות משמעות קריטית — לדוגמה ניתוח סנטימנט, בו 'not good' שונה מהותית מ-'good', או במודלי שפה/embeddings שמרוויחים מהקשר תחבירי מלא.
