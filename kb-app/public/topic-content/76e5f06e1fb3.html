📋 הגדרה

מודל שפה מבוסס Transformer Encoder-only, המאומן באופן דו-כיווני (Bidirectional) על משימות Self-Supervised כדי להפיק ייצוגים תלויי-הקשר (Contextual Embeddings) עבור מילים וטקסטים.

🏛️ מבנה הרשת

  • Stack של Transformer Encoder Layers (12 ב-BERT-Base, 24 ב-BERT-Large)
  • Token Embeddings + Segment Embeddings + Positional Embeddings בכניסה
  • טוקן [CLS] בתחילת הרצף — ייצוג מסכם לכל הרצף, משמש למשימות סיווג
  • טוקן [SEP] — מפריד בין שני משפטים/קטעים בקלט (לדוגמה ב-Next Sentence Prediction)

📐 נוסחאות מפתח

Masked Language Modeling — שני שלבי האימון המקדים העיקריים:

🎯 תחומי שימוש

  • חילוץ ייצוגים תלויי-הקשר למשימות הבנת טקסט
  • Fine-tuning למשימות Downstream: סיווג טקסט, NER, Question Answering
  • בסיס ל-Bi-Encoder Retrieval ולחיפוש סמנטי

✅ יתרונות

  • דו-כיווניות (Bidirectional) — כל טוקן רואה הקשר משני הצדדים, בניגוד למודלים אוטורגרסיביים
  • ייצוגים תלויי-הקשר (Contextual) — אותה מילה מקבלת וקטור שונה בהקשרים שונים
  • Transfer Learning יעיל — Fine-tuning קצר על משימה ספציפית לאחר Pretraining יקר חד-פעמי

❌ מגבלות

  • לא בנוי ליצירת טקסט (Generation) — מתאים להבנה (Understanding) ולא לדקודינג אוטורגרסיבי
  • גודל קלט מוגבל (בד"כ 512 טוקנים)
  • Pretraining יקר מאוד מבחינת חישוב ודאטה

💻 קוד לדוגמה (PyTorch)

from transformers import BertTokenizer, BertModel

tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

inputs = tokenizer(&quot;Deep learning is powerful&quot;, return_tensors=&quot;pt&quot;)
outputs = model(**inputs)
cls_embedding = outputs.last_hidden_state[:, 0, :]  # [CLS] representation

🧠 שאלות ראיון נפוצות

ש: מה ההבדל בין BERT ל-GPT?

ת: BERT הוא Encoder-only ודו-כיווני, מתאים להבנת טקסט; GPT הוא Decoder-only וחד-כיווני (אוטורגרסיבי), מתאים ליצירת טקסט.

ש: מה זה Masked Language Modeling (MLM)?

ת: משימת אימון מקדים שבה אחוז מהטוקנים ברצף מוסתר (Mask), והמודל מתבקש לחזות אותם מתוך ההקשר משני הצדדים — זה מה שמכריח דו-כיווניות.
