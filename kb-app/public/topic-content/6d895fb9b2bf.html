📋 הגדרה

LLMs הם stateless מטבעם (אין להם זיכרון מובנה). Agentic Memory הוא המנגנון המאפשר ל-Agent לשמר הקשר שיחה/אינטראקציה — ברמת session בודד (קצר-טווח) או בין sessions שונים (ארוך-טווח).

🏛️ סוגי זיכרון

סוגתיאורדוגמה
Short-term (Session-based)שומר הקשר שיחה ופניות המשתמש בתוך session בודדבוט טריאז' רפואי: "כאב בבטן" → "זה התחיל אתמול" מקושר אוטומטית
Long-term (Persistent)שומר הקשר בין sessions שוניםמורה פרטי: זוכר שבסשן קודם הלומד התקשה ב-eigenvalues
Hybrid (Context + DB)שילוב זיכרון session עם מסד נתונים/וקטורי חיצונימתכנן טיולים: שולף תוכנית טיול ישנה ממסד וקטורי ומעדכן אותה

🎯 מתי להשתמש בכל סוג

  • Short-term מתאים כשצריך המשכיות תוך שיחה בודדת בלבד (תמיכה, טריאז').
  • Long-term מתאים כשצריך לזכור עובדות/העדפות אישיות על פני זמן (הוראה, ליווי לקוח מתמשך).
  • Hybrid מתאים כשיש גם הקשר שיחה מיידי וגם נתונים היסטוריים שצריך לשלוף (תכנון מורכב, ניהול פרויקטים).

🔄 קשר לנושאים אחרים

Agentic Memory הוא ההרחבה הכללית של מנגנון ה-memory שנדון ב-Conversational RAG — שם מדובר ספציפית בזיכרון לצורך retrieval-augmented QA, וכאן במנגנון הזיכרון הכללי של Agent בכל סוג משימה.

🧠 שאלות ראיון נפוצות

ש: למה LLMs נחשבים stateless, ומה המשמעות המעשית?

ת: LLM מעבד כל קריאה (API call) ללא זיכרון מובנה של קריאות קודמות — כל מה ש-"זוכר" Agent חייב להיות מוזרק מחדש ל-prompt על ידי שכבת ה-memory החיצונית.

ש: מתי תבחר ב-Hybrid Memory על פני Long-term Memory בלבד?

ת: כשצריך גם המשכיות מיידית תוך שיחה (קונטקסט session) וגם גישה לנתונים היסטוריים ממקור חיצוני (DB/Vector Store) — לדוגמה עדכון תוכנית טיול קיימת בסשן חדש.
