📋 הגדרה

שיטת רגולריזציה המכבה (מאפסת) באופן אקראי אחוז מסוים מהנוירונים בכל מעבר אימון, כדי למנוע מהרשת להסתמך יתר על המידה על נוירונים בודדים ולשפר הכללה (generalization).

⚙️ איך זה עובד

  1. בוחרים הסתברות p לכיבוי נוירון (לדוגמה p=0.5).
  2. בכל מעבר אימון (Forward Pass) מגרילים מסכה בינארית אקראית לכל נוירון בשכבה.
  3. מאפסים את הפלט של הנוירונים שנבחרו לכיבוי, ומשנים קנה מידה (scale) לשאר לפי 1/(1-p).
  4. בזמן Inference מבטלים את ה-Dropout ומשתמשים בכל הנוירונים (ללא כיבוי אקראי).

🎯 שימושים עיקריים

  • מניעת Overfitting ברשתות עמוקות עם הרבה פרמטרים (MLP, CNN)
  • שיפור robustness של המודל כשדאטה האימון מוגבל

✅ יתרונות

  • מפחית Overfitting ביעילות וזול חישובית
  • פועל כסוג של Ensemble מרומז (כל מעבר אימון "מאמן" תת-רשת אחרת)
  • קל להוספה לכל שכבה קיימת

❌ חסרונות / מגבלות

  • מאריך את זמן ההתכנסות (נדרשות יותר epochs)
  • לא יעיל באותה מידה בשכבות Convolution כמו בשכבות Fully-Connected
  • צריך לזכור להשבית אותו ב-Inference (model.eval())

💻 קוד לדוגמה (Python / PyTorch)

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(p=0.5),   # מכבה 50% מהנוירונים בזמן אימון
    nn.Linear(256, 10),
)

model.train()  # Dropout פעיל
model.eval()   # Dropout מושבת — נדרש לפני Inference

🧠 שאלות ראיון נפוצות

ש: למה Dropout צריך scaling ב-1/(1-p) בזמן אימון?

ת: כדי שהציפייה (expected value) של הפלט תישאר זהה בין אימון להסקה, ולכן בזמן הסקה (כש-Dropout מושבת) אין צורך לבצע נרמול נוסף.

ש: למה חשוב לקרוא ל-model.eval() לפני הערכת המודל?

ת: כי זה משבית את ה-Dropout (ואת ה-Batch Norm במצב running stats), כך שההסקה דטרמיניסטית ומשתמשת בכל הרשת המלאה.
