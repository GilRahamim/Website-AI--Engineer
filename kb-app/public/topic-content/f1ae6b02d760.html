📋 הגדרה

YOLO (You Only Look Once) הוא משפחת מודלי Deep Learning לזיהוי אובייקטים (object detection) בזמן אמת. הרעיון המרכזי: המודל 'מסתכל' על התמונה פעם אחת בלבד, ומחזיר במעבר יחיד מה קיים בתמונה, היכן הוא ממוקם (bounding box), ומה רמת הביטחון (confidence) — ללא צורך בסריקה אזורית מרובת-שלבים כמו בגישות זיהוי קלאסיות יותר.

🏛️ מבנה ויכולות

  • מהיר ביותר — תוכנן לעבודה ב-real time.
  • תומך במשימות מרובות מאותה ארכיטקטורת בסיס: Detection, Segmentation, Pose Estimation, Classification, Tracking.
  • Ultralytics (היצרן) מפיץ YOLOv8 כקוד פתוח, עם רישוי AGPL לתרחישי שימוש מסוימים בגרסאות החדשות יותר.

⚙️ Setup והרצה בסיסית

pip install ultralytics opencv-python

from ultralytics import YOLO

model = YOLO("yolov8s.pt")

📚 דאטהסט COCO (Common Objects in Context)

COCO הוא אחד מדאטהסטי ה-Computer Vision החשובים ביותר — כולל 80 קטגוריות אובייקטים, מיליוני annotations, bounding boxes, segmentation masks, ו-human keypoints. דוגמאות קטגוריות: Person (class 0 ב-COCO), Car, Dog, Laptop, Bottle.

💻 קוד לדוגמה — זיהוי אובייקטים מ-webcam

זרימת העבודה: Camera → YOLO → Detection → Drawing → Display.
# 01_object_detection.py
results = model(frame)
annotated = results[0].plot()

⚖️ FPS וטרייד-אוף מהירות/דיוק

FPS (Frames Per Second) מודד כמה תמונות בשנייה המודל מעבד. מודלים קטנים יותר → מהירים יותר; מודלים גדולים יותר → מדויקים יותר. בחירת גודל המודל (s/m/l/x) היא החלטת trade-off ישירה בין latency לאיכות detection.

✅ יתרונות

  • מהירות real-time — מתאים ליישומי וידאו חיים.
  • ארכיטקטורה אחת מספקת בסיס למספר משימות CV (detection/seg/pose/cls/tracking).
  • קל לשימוש — API פשוט (model(frame)) עם הדמיה מובנית (.plot()).

❌ מגבלות

  • טרייד-אוף מהירות/דיוק — לא ניתן למקסם את שניהם בו-זמנית עם אותו מודל.
  • ביצועים נפגעים בתאורה גרועה, חפיפה (occlusion), טשטוש תנועה, ואובייקטים קטנים.

🧠 שאלות ראיון נפוצות

ש: מה ההבדל המהותי בין YOLO לגישות detection ישנות יותר (כגון two-stage detectors)?

ת: YOLO מבצע single-pass — חוזה bounding boxes ו-class probabilities במעבר רשת יחיד על כל התמונה. גישות two-stage (כמו R-CNN המקורי) מפרידות בין שלב הצעת אזורים (region proposal) לשלב סיווג — מדויקות יותר היסטורית אך איטיות בהרבה, ולכן לא מתאימות ל-real time.

ש: מדוע COCO הוא דאטהסט הבנצ'מארק הסטנדרטי להערכת מודלי detection?

ת: כי הוא מספק annotations עשירים (bounding boxes, masks, keypoints) על פני 80 קטגוריות מגוונות ומיליוני דוגמאות — מאפשר השוואה הוגנת ועקבית בין מודלים שונים על משימות detection, segmentation, ו-pose.
