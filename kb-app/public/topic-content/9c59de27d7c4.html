הגדרה

שכבה סטטיסטית מעל Matplotlib, שמקבלת DataFrame ושמות עמודות במקום מערכים גולמיים. גרף שדורש עשרות שורות ב-Matplotlib — כולל אגרגציה, רווחי סמך וצבע לפי קטגוריה — נכתב כאן בשורה אחת.

גרפי התפלגות

  • histplot(df['col'], bins=30, kde=True) — התפלגות משתנה יחיד.
  • kdeplot — אומדן צפיפות חלק, בלי הרעש של בחירת ה-bins.
  • jointplot(x=, y=, data=, kind=) — קשר בין שני משתנים עם ההתפלגויות השוליות בשוליים. kind יכול להיות scatter, reg, kde או hex.
  • pairplot(df, hue='cat') — כל זוגות המשתנים הרציפים בטבלה בבת אחת. הכלי הראשון שכדאי להריץ על דאטה חדש.

מטריצות ורשתות

  • heatmap(df.corr(), annot=True, cmap='coolwarm') — מטריצת מתאמים. annot מציג את הערכים, cmap קובע את סקאלת הצבע.
  • FacetGrid(df, col='c1', row='c2') — אותו גרף חוזר לכל שילוב קטגוריות. השיטה הישירה: relplot או displot עם col ו-row.
  • PairGrid — גרסה ידנית של pairplot: אפשר גרף שונה באלכסון, במשולש העליון ובתחתון.
  • lmplot(x=, y=, data=, hue=, col=) — פיזור עם קו רגרסיה ורצועת אי-ודאות, מפוצל לפי קטגוריות.

קוד לדוגמה

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset('tips')      # גם 'flights' ו-'iris' מובנים
sns.set_style('whitegrid')

# התפלגות
sns.histplot(tips['total_bill'], bins=30, kde=True)

# קשר בין שני משתנים, מפוצל לפי קטגוריה
sns.lmplot(x='total_bill', y='tip', data=tips, hue='sex', col='time')

# השוואה בין קבוצות
sns.boxplot(x='day', y='total_bill', data=tips, hue='smoker',
            palette='coolwarm')

# מתאמים
plt.figure(figsize=(8, 6))
sns.heatmap(tips.corr(numeric_only=True), annot=True, cmap='coolwarm',
            linewidths=1)

שאלות ראיון נפוצות

ש: מתי Seaborn ומתי Matplotlib?

ת: Seaborn לגרפים סטטיסטיים סטנדרטיים מתוך DataFrame — התפלגויות, השוואות בין קבוצות, מתאמים. Matplotlib כשצריך שליטה מדויקת בפריסה או גרף לא סטנדרטי. הן לא מתחרות: Seaborn מחזירה אובייקט Axes של Matplotlib, אז אפשר להתחיל בגבוהה ולרדת לנמוכה לכוונון.

ש: מה ההבדל בין barplot ל-countplot?

ת: countplot סופר כמה שורות יש בכל קטגוריה ומקבל רק ציר אחד. barplot מקבל גם משתנה מספרי ומציג אגרגציה שלו לכל קטגוריה — ברירת המחדל ממוצע, עם רצועת רווח סמך. countplot שקול ל-barplot עם ספירה.

ש: מה boxplot מסתיר ש-violinplot מראה?

ת: boxplot מציג חמישה מספרים בלבד, ולכן שתי התפלגויות שונות לגמרי — למשל חד-שיאית מול דו-שיאית — יכולות להיראות זהות בו. violinplot מוסיף את אומדן הצפיפות ומגלה את הצורה האמיתית.
