קוד לדוגמה — תמונה לטקסט (LiteLLM)

import base64, mimetypes
from litellm import completion

def to_data_url(path):
    mime = mimetypes.guess_type(path)[0] or "image/png"
    b64  = base64.b64encode(open(path, "rb").read()).decode()
    return f"data:{mime};base64,{b64}"

messages = [{
    "role": "user",
    "content": [
        {"type": "text", "text": "Describe this photo briefly."},
        {"type": "image_url",
         "image_url": {"url": to_data_url("local_data/example.png")}},
    ],
}]
resp = completion(model="gpt-4o", messages=messages, temperature=0.2)
description = resp.choices[0].message.content

שאלות ראיון נפוצות

ש: למה ממירים הכל לטקסט במקום להזין מודל מולטי-מודלי ישירות?

ת: כי אחרי ההמרה כל התשתית הקיימת עובדת: אפשר לאנדקס את הטקסט ב-vector store, להריץ עליו RAG, לשמור אותו בזיכרון של ה-agent ולהעביר אותו בין agents. טקסט הוא גם זול ובר-בדיקה, בעוד שהזנת תמונה בכל שלב מייקרת ומקשה על דיבאג.

ש: מתי OCR ומתי מודל מולטי-מודלי?

ת: OCR כשצריך את הטקסט המדויק ממסמך מודפס ונקי — הוא מהיר, זול ורץ מקומית. מודל מולטי-מודלי כשצריך הבנה של התמונה עצמה, כשהפריסה מורכבת, או בכתב יד — שם OCR קלאסי נכשל.

ש: איך מנתחים וידאו ביעילות?

ת: מפצלים לשני ערוצים: פס הקול מתומלל פעם אחת ונותן את רוב המידע בעלות נמוכה; הפריימים נדגמים בקצב נמוך ומנותחים רק כשהתמלול אינו מספיק. דגימת כל פריים היא כמעט תמיד בזבוז.
