📋 הגדרה

שיטה המנרמלת את האקטיבציות של שכבה (לממוצע 0 ושונות 1) על פני כל מיני-באטץ' באימון, ולאחר מכן מאפשרת לרשת ללמוד קנה מידה (scale) והיסט (shift) משלה — מייצבת ומאיצה את האימון.

⚙️ איך זה עובד

  1. בכל מיני-באטץ' מחשבים את הממוצע והשונות של האקטיבציות בכל ערוץ/נוירון.
  2. מנרמלים את האקטיבציות: מחסרים את הממוצע ומחלקים בשורש השונות (פלוס אפסילון).
  3. מכפילים בפרמטר γ (scale) ומוסיפים פרמטר β (shift) — שני פרמטרים נלמדים.
  4. בזמן Inference משתמשים בממוצע/שונות גלובליים (running statistics) שנאספו באימון, ולא בסטטיסטיקת ה-batch הנוכחי.

📐 נוסחאות

נרמול:

Scale & Shift:

🎯 שימושים עיקריים

  • אימון רשתות עמוקות (CNN, MLP) שבהן ההתפלגות הפנימית של האקטיבציות משתנה במהלך האימון (internal covariate shift)
  • מאפשר שימוש ב-learning rate גבוה יותר ומקצר זמן אימון

✅ יתרונות

  • מאיץ משמעותית את התכנסות האימון
  • מאפשר learning rate גבוה יותר ביציבות
  • פועל גם כרגולריזציה קלה (מפחית Overfitting)

❌ חסרונות / מגבלות

  • תלוי בגודל batch — לא עובד טוב עם batch קטן מאוד
  • מוסיף תקורת חישוב וזיכרון (שמירת running stats)
  • פחות מתאים ל-RNN (שם Layer Normalization עדיף)

💻 קוד לדוגמה (Python / PyTorch)

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.BatchNorm1d(256),  # מנרמל את האקטיבציות לפני ReLU
    nn.ReLU(),
    nn.Linear(256, 10),
)

🧠 שאלות ראיון נפוצות

ש: מה זה internal covariate shift ואיך Batch Norm פותר אותו?

ת: זו התופעה שבה התפלגות הקלט לכל שכבה משתנה במהלך האימון כתוצאה מעדכוני המשקלים בשכבות הקודמות; Batch Norm מנרמל מחדש את ההתפלגות בכל שכבה, מה שמייצב ומאיץ את האימון.

ש: מה ההבדל בין Batch Norm באימון לבין ב-Inference?

ת: באימון משתמשים בממוצע/שונות של ה-batch הנוכחי; ב-Inference משתמשים בממוצע/שונות גלובליים (running mean/var) שנאספו במהלך כל האימון, כדי שהתחזית תהיה דטרמיניסטית.
